# 새 체험 콘텐츠와 공공 API 연결

확인일: 2026-11-14. 대상: https://mwohaji.kr

사용자 수정 요청에 따라 지역별 실제 카드와 내부 상세 페이지로 다시 구성했다. 아래 최초 수집에 청소년 상세 API 118건, 농어촌 상세 필드와 장소·사진 대조를 보강했다. 현재 구조와 검증은 `docs/internal-experience-pages-20261114.md`를 기준으로 한다.

## 반영 범위

사용자가 요청한 새 콘텐츠는 가족 체험, 과학관 교육·행사, 농촌 체험이다. 별도 `/experiences` 허브와 세 가지 주제를 만들고 홈에 각각의 진입점을 둔다. 기존 강좌·나들이의 지역별 변형 페이지 수를 늘리는 방식으로 대체하지 않는다.

| 새 주제 | 원자료 | 오늘 실제 수집 | 방문자가 확인할 내용 |
|---|---|---|---|
| 농촌·어촌 체험 | [전국농어촌체험휴양마을표준데이터](https://www.data.go.kr/data/15013113/standard.do), 한국농어촌공사·한국어촌어항공단 | 1,261개 마을, API 2회 | 수확·음식·공예·생태 프로그램, 주소, 기관, 문의처, 원자료 기준일 |
| 어린이·청소년 체험 | [성평등가족부 방학 중 프로그램](https://www.data.go.kr/data/15073963/openapi.do) | 전체 3,575개 중 종료되지 않은 활동 118개, API 4회. 화면에는 체험 관련 활동 선별 | 활동기간·지역·참가비·기관·명시된 대상과 내용. 숫자만 있는 target 필드는 나이로 해석하지 않음 |
| 과학관 교육·체험 | [국립중앙과학관 전체 교육](https://www.science.go.kr/mps/1092/allEduPrograms.do), [인천학생과학관 특별 프로그램](https://aicei.ice.go.kr/science/cm/cntnts/cntntsView.do?cntntsId=1047&mi=1112) | 공식 교육 일정 2곳, 현재 프로그램 14개 | 교육일정·대상·접수일·실제 공식 예약 링크. 과학관 전국 전체 수집으로 표시하지 않음 |

농촌 API는 저작자표시 조건, 청소년 API는 이용허락범위 제한 없음으로 표시됐다. 두 신청은 사용자의 실행 시점 동의를 받은 후 승인 상태를 확인했다. 기존 통합 인증키를 재사용하며 비밀키를 새 공개 파일에 저장하지 않는다. 서울 열린데이터광장 신청은 사용자의 지시로 제외했다.

과학관 공공데이터포털 검색에서는 2020~2025년의 일회성·과거 행사 자료가 확인됐다. 이를 현재 모집 정보로 게시하지 않고, 실제 2026년 공식 교육 일정을 확인하는 수집기를 연결했다. API 연결과 공개 웹 일정 확인을 같은 방식으로 설명하지 않는다.

추가로 승인된 전국평생학습강좌 API에서 29,637개 중 진행·예정 문화·취미 강좌 2,832개를 저장했다. 접수기간 내·접수예정 조건은 별도로 적용한다. 한국관광공사 무장애 여행 API에서는 전국 목록 4,804개를 대조하고 17개 시도 51곳의 상세 안내를 확보했다. 모든 장소의 접근성을 인증하거나 전체 상세 수집이 끝났다고 표시하지 않는다.

## 공개 경로와 검색 구성

- `/experiences`: 새 체험 주제 허브
- `/experiences/family`: 어린이·청소년 체험 활동
- `/experiences/science`: 과학관 교육·체험 프로그램
- `/experiences/rural`: 농촌·어촌 체험마을
- `/classes`, `/classes/free`, `/classes/weekend`, `/classes/family`: 문화·취미 강좌
- `/accessible-travel`: 이동·영유아 편의정보

홈·메뉴·푸터와 사이트맵에서 연결한다. 17개 지역 목록과 개별 내부 상세를 제공하고, 각 페이지에 고유 제목·설명·canonical 및 본문과 일치하는 구조화 데이터를 적용한다. 검색 조건과 페이지 번호가 붙은 변형은 noindex,follow로 두며 내용이 충분한 상세만 사이트맵에 넣는다. 카드의 주 링크는 내부 상세이고 신청·예약 버튼은 공식 외부 경로를 사용한다.

## 갱신과 사실 판정

일일 workflow가 농어촌·청소년 API, 과학관 일정, 문화 강좌를 확인하고 변경된 JSON을 기존 방식으로 커밋한다. NAS는 기존 main 동기화 작업으로 변경 자료를 반영한다. 방문자의 페이지 조회는 외부 기관 API를 호출하지 않는다. 초기 수집은 실제 확인했고, 배포 이후의 다음 정기 실행 성공 여부는 별도 실행 결과로 판단한다.

API 페이지 누락·전체 건수 변화·인증 오류가 생기면 새 파일로 교체하지 않는다. 과학관 기관별 실패는 기존 설명과 해당 기관의 마지막 확인시각을 보존하고 부분 실패로 남긴다. 종료 프로그램은 화면에서 날짜 기준으로 제외한다. 확인을 마친 유효한 빈 시즌은 수집 누락과 구별한다.

농촌 프로그램의 계절·운영일·가격·연령을 추정하지 않는다. 청소년 참가비 무료는 명시된 무료 또는 0원만 사용한다. 과학관의 접수 마감과 교육 종료를 구별하고, 접수기간만으로 잔여석이 있다고 표현하지 않는다. 유모차·휠체어 대여 안내로 출입 가능 여부를 추정하지 않으며 계단·경사·불가 설명을 그대로 보존한다.

무장애 API는 화~일 최대 60회, 월요일 0회로 설정한다. 기존 한국관광공사 보수 예산은 월요일 1,000회, 그 외 410회다. 별도 제공기관인 강좌·농어촌·청소년 API는 각각 페이지 수 상한을 둔다. 쿠팡 상품 API는 이 작업에서 호출하지 않는다.

## 재료가이드 수정

재료가이드 33개의 기존 원본 이미지를 실제로 확인하고 중복 제목띠 합성본을 화면에서 제외했다. 재료 사진은 대표 이미지, 완성 사진은 본문에 배치했다. 59개 이미지 필드 변경을 `data/prep-image-edits-20261114.json`에 기록했다. 기존 44개 글의 URL·발행 상태·본문·제휴 추적 URL 보존 검사를 통과했다. 기존 공개 이미지 파일의 서버 완전 삭제를 주장하지 않는다.

## 효과 확인

신규 주제의 공개와 실제 검색 유입 증가는 다른 결과다. 아직 신규 메뉴의 노출·조회수·매출 증가를 측정하지 않았다. 공개 후 Search Console에서 이 경로들의 노출·클릭·CTR을 주제별로 비교하고, 기존 GA 페이지 조회와 공식 신청처로 이어지는 이용 흐름을 확인한다. 순위나 방문자 증가를 보장하지 않는다.
