# 체험·교육 글 정리와 반응형 보완

2026-11-15 작업. 기존 글의 ID·URL·원자료·기관 신청 주소·사진 출처를 유지하고 체험 및 강좌의 공통 표시 방식을 개선했다.

## 원인과 변경

- 청소년 공개자료 118건 중 12건의 본문에 문장 앞 `?`가 머리기호 대신 들어 있었다. 이미 저장된 자료의 표시 단계와 향후 수집 단계 모두에서 이 기호를 정리한다. 문장 속 질문과 URL 쿼리 문자는 보존한다.
- 기간·장소·대상·인원 등 명시된 항목만 정보표로 구분한다. `대학생 : 중학생 1:2` 같은 문장은 일반 활동 내용으로 보존한다. 활동은 목록, 설명은 문단으로 표시한다. 원문에서 이어 붙은 목록 기호와 일부 HTML 문자표기도 정리한다.
- 긴 제목과 요약, 소제목, 본문, 출처의 줄 간격과 여백을 통일했다. 긴 소개는 짧은 요약과 전체 본문으로 나눠 보여준다. 원자료에 없는 경험이나 활동 내용은 작성하지 않았다.
- 상세 화면은 PC에서 본문과 고정 신청 안내를 두 열로 배치하고, 1000px 이하에서는 사진 → 참여 요약 → 본문 순서로 읽힌다. 사진이 없으면 빈 이미지 영역을 만들지 않는다. 작은 공식 이미지를 강제로 확대하지 않는다.
- 17개 지역과 분야별 목록의 필터 너비, 46px 입력칸, 버튼 간격, 카드 글자와 줄바꿈을 보완했다. 360px 미만에서는 카드를 한 열로 표시한다. 강좌 목록과 내부 상세에도 같은 읽기 기준을 적용했다.
- 공통 상세 화면을 쓰는 편의정보 페이지도 정보표와 반응형 회귀 검사를 포함했다. 제휴 데이터 및 추적 주소는 수정하지 않았다. 상품 API는 호출하지 않았다.

## 로컬 검증

- 관련 단위 검사: 체험·사진·본문 정리 18건 통과. 강좌·공공자료 관련 5건도 통과.
- 프로덕션 빌드: Next.js 컴파일·타입 검사 및 정적 페이지 1,460개 생성 통과. 다른 기존 화면의 이미지·Hook 린트 경고는 남아 있다.
- 전체 HTTP 검사: 체험 상세 1,397건, 강좌 2,832건, 편의정보 100건과 목록·지역·검색·사이트맵·이미지 검사를 포함해 4,354건 통과. H1·canonical·본문 보존·공식 신청 주소·지역 분리·본문 바로가기·깨진 머리기호를 확인했다.
- 제보한 상세 글은 320·360·390·430·640·768·820·1024·1440px에서 가로 넘침 0건. 지역 목록은 320·390·768·1024·1440px에서 가로 넘침 0건.
- 청소년 장문, 과학관, 농촌, 강좌 상세와 강좌 목록을 320·768px에서 추가 확인했다. 경기 지역의 가평군 선택은 체험 14개를 표시했다.

브라우저 및 HTTP 상세 기록은 작업본의 `.cache/experience-qa/`와 `.cache/internal-experience-local.json`에 보관한다. 운영 반영 결과는 공개 배포 버전과 실제 페이지를 확인한 뒤 추가한다.
