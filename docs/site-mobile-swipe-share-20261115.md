# 모바일 공유·먹거리 스와이프 개선 (2026-11-15)

## 변경

- 공통 레이아웃에서 화면을 따라다니던 공유 버튼을 제거했다. 푸터의 `홈페이지 링크 복사`는 문서 흐름 안에 있으며 현재 페이지가 아닌 홈페이지 주소를 복사한다.
- 복사 완료 안내도 버튼 옆에서만 알린다. 버튼의 최소 높이는 44px이며 연속 클릭/화면 이동 시 타이머를 정리한다.
- 오늘의 먹거리 특가는 유효한 상품 전체를 한 줄로 표시한다. 상품 더보기/이전 페이지 버튼을 제거했다. 휴대폰의 기본 터치 스크롤, PC 마우스 드래그, 방향키/Home/End, 스크롤바로 이동한다.
- 마우스 드래그 중 React 상태를 갱신하지 않는다. 드래그 직후 상품 링크가 잘못 열리는 것을 막고, 클릭 및 키보드 링크 작동은 보존한다.
- 화면 크기에 따라 카드 폭을 조정하고 다음 카드의 일부를 보여준다. 할인율·가격·상품명·이미지·원본 제휴 링크·광고 표시·분류·품절/마감/자료 만료 검사를 유지한다.
- 푸터 링크가 한꺼번에 경로를 미리 읽지 않도록 `prefetch={false}`를 적용했다. 가격/시간 표시용 Intl formatter를 재사용한다. 새 실행 의존성이나 캐러셀 라이브러리는 추가하지 않았다.

기존에 설치된 UI/UX Pro Max, Vercel React Best Practices, web-perf 스킬을 사용했다. GitHub의 공식 저장소와 Vercel 규칙 원문을 확인했다.

- https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices
- https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

## 검증 기록

- 먹거리/제휴 정책/만료/사이트 자료 회귀 검사: 29개 통과. 실제 쿠팡 API는 호출하지 않았다.
- 수정 TSX 대상 ESLint: 오류 0개. 기존 방식인 외부 상품 `<img>`에 관한 권고 경고가 있다.
- 실제 브라우저: 10개 유효 상품의 원본 이름·가격·사진·제휴 링크 일치, 드래그 후 가로 이동, 잘못 열린 새 탭 0개, Home/End/방향키, 분류 변경 후 스크롤 초기화 확인.
- 운영용 빌드 성공 (Next.js 15.5.21, 정적 페이지 1,459개 생성). 타입 검사 및 수정 파일 lint 오류 0개. 프로젝트의 기존 이미지/Hook 권고 경고는 남아 있다.
- 운영용 로컬 서버에서 홈·체험·문화행사·준비 가이드·맛집·캠핑·여행코스·나들이·게임의 9개 경로 × 320/390/768/1280px, 총 36개 조합 통과: 문서 가로 넘침 없음, 완료된 이미지의 로딩 실패 없음, H1 1개, 일반 페이지의 푸터 복사 버튼은 문서 내 배치/44px. 게임 집중 화면에서는 기존 규칙대로 푸터를 숨긴다.
- 새 운영용 브라우저 탭의 JavaScript console 오류 0개. 체험 카드 → 내부 상세(본문 소제목 6개), 모바일 문화행사 무료 필터와 전체 메뉴 작동 확인.
- 체험 상세·17개 지역 목록·내부 링크·canonical/설명/H1/구조화 자료·사이트맵·이미지 등 81개 읽기 전용 HTTP 검사 통과.
- 공개 배포 완료 조건: NAS 작업 `정상 (0)`, `/api/site-status`의 실제 commit 일치, 공개 화면의 드래그/공유/반응형 재검사. 릴리스 증거는 `.cache/site-mobile-*`에 저장한다.

개발 서버의 Fast Refresh 중 DOM 오류가 관찰되어 운영용 빌드와 새 브라우저 탭에서 재검사했고 재현되지 않았다. DevTools 성능 트레이스 수집 기능이 제공되지 않아 LCP/INP/CLS 또는 Lighthouse 점수 개선을 수치로 주장하지 않는다. 단일 HTTP 응답 시간은 Core Web Vitals가 아니다.
