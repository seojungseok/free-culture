# 겨울 1박 2일 20개 추가

2026-11-07 사용자 요청에 따라 기존 당일치기 20개와 URL·사진을 보존하고, 별도 검토한 1박 2일 글 20개를 추가한다.

## 콘텐츠와 근거

- 신규 글은 17개 검색 지역에 배분했다. 강원·전남·경북은 각 2개, 나머지 지역은 각 1개다.
- 86개 방문지를 1일차·2일차로 구분했다. 각 날 2곳 이상이며, 식사·휴식·숙박 권역·현지 도착과 귀가·겨울 대체 일정을 설명한다.
- 공식 기관 자료로 운영 정보를 확인했다. 안동시립박물관 휴관 장소를 제외했고 대통령기록관의 11월 부분 개관, 박물관과 전망대의 서로 다른 휴무, 청남대의 동절기 입장 마감을 반영했다.
- 네이버 공개 검색 20건은 발견 경로로 사용했다. 사실 근거는 운영기관·지자체·관광공사 자료이며 글마다 출처와 확인일을 공개한다.
- 한국관광공사 Type1 사진 70장을 장소 ID와 대조하고 시각 검토했다. 글마다 서로 다른 사진 3~5장이 있으며 원본 주소·출처·검토 시각을 보존한다. 일반 계절 사진은 자료 사진으로 표시한다.
- 이동 동선의 인접 지점 직선거리 최대값은 34.28km다. 이 값은 도로 거리나 소요 시간으로 표시하지 않는다. 본문 시간은 현지 관람 제안이며 교통 시간표가 아니다.

자세한 근거는 `winter-overnight-research-a-20261107.md`, `winter-overnight-research-b-20261107.md`, `winter-overnight-api-photo-audit-20261107.md`를 참조한다.

## 화면과 공개 기준

- 메인에서 전체·당일치기·1박 2일과 지역을 함께 선택한다. 카드 미리보기는 기존 반응형 한 줄을 유지한다.
- `/winter-travel`은 40개 글을 서버에서 렌더링하고 일정·지역·검색어를 조합해 고른다. `duration=daytrip|overnight`를 URL에 유지하며 띄어쓰기가 다른 검색어도 찾는다.
- 상세 페이지는 이틀의 순서를 나누고 숙박 권역을 보여 준다. 동일 사진은 중복 노출하지 않으며 추가 자료 사진도 본문과 Article 이미지에 포함한다.
- 제목·설명·canonical·Article·Breadcrumb·ItemList와 사이트맵은 실제 공개 데이터에 맞춘다. 필터 조합은 별도 사이트맵 URL로 양산하지 않는다.
- 새 version 3 공개 검증은 양일 일정, 공식 출처, 검토된 사진·원본 주소·대표 이미지, 숙박 권역을 요구한다. 자료가 미비한 글은 목록과 사이트맵에서 제외한다.
- 자동 생성 발행은 계속 비활성화되어 있다. 조립은 검토한 원고와 장소 증거에 `node scripts/build-winter-overnights.mjs --reviewed`를 적용한다. 기존 당일치기 조립기는 실행하지 않는다.

## 검증

- 겨울 코스·발행·사진 회귀 테스트 18개 통과.
- 운영 빌드 통과. Windows 빌드 워커 종료 후 이번 작업의 빌드 캐시만 정리하고, 단일 워커·Webpack 캐시 비활성화로 재검증했다. 임시 설정은 복원했으며 배포 설정 변경은 없다.
- 로컬 운영 서버 HTTP 검사 197/197 통과: 겨울 글 40개, 목록, 사이트맵, 사진 130장, 폐기 URL 17개, 기존 주요 페이지 8개.
- 브라우저에서 1박 2일 20개·당일치기 20개 전환, 지역과 일정 조합, 띄어쓰기 없는 `1박2일` 검색을 확인했다. 독립 검토에서도 발행을 막는 오류가 발견되지 않았다.
- `node scripts/testSeo.cjs` 통과: canonical 대상, 사이트맵 중복·실제 레코드 연결, robots 허용 범위 등.
- 원래 당일치기·성동 한장 행사·제휴 데이터의 Git 차이가 없음을 확인했다.
- `scripts/check-winter-release.mjs`는 로컬과 운영 사이트의 40개 상세, 목록·사이트맵, 기존 폐기 URL, 전체 사진, 대표 기존 페이지를 실제 HTTP로 확인한다. 운영 반영 여부는 이 결과와 `/api/site-status`의 배포 커밋으로 구분한다.

## Google 요청 구분

개별 URL 색인 요청, 사이트맵 접수, Google의 실제 색인 생성은 별도 상태다. 2026-11-07 개별 행사 URL 재요청에서 Google reCAPTCHA 연결 오류가 관찰되었으며, 접수되지 않은 요청을 완료로 기록하지 않는다. 배포 후의 사이트맵 제출 결과와 공개 HTTP 검증은 별도 운영 증거로 남긴다. 노출 순위나 색인 시점을 보장하지 않는다.
