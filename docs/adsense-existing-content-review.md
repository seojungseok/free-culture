# AdSense 기존 글 품질 보완 운영

신규 자동 글 발행은 `data/publication-policy.json`의 `newPublicationEnabled: false`로 중지한다. 이 설정은 일일 작업뿐 아니라 관광지·여행코스·시티투어 생성기를 직접 실행해도 적용된다. 재개는 편집 책임자가 명시적으로 검토한 뒤에만 한다.

## 매일 자동으로 하는 일

- 시간에 민감한 행사·축제 등 공공 데이터만 갱신한다.
- `scripts/auditArticles.mjs --write`가 관광지 본문의 얇음·추측성·반복 후보를 표시한다.
- `scripts/auditPublishedContent.mjs --write`가 공개 관광지·여행코스·시티투어에 `qualityAudit` 표식을 기록한다.
- 이 과정은 URL, slug, 본문, 이미지, 제휴 링크, 공개 상태를 바꾸지 않는다.

## 편집 우선순위

1. `qualityAudit.priority: high`: 1차·교차 검증 모두 통과하지 않았거나, 원본 코스·공식 운행 주소·기준일이 없는 글이다. 원본 공식 자료를 찾기 전에는 문장을 늘리거나 추천 강도를 높이지 않는다.
2. `qualityAudit.priority: review`: 검수 불일치, 반복 문단, 짧은 본문, 자동 조합 코스의 체류시간, 오래된 운행·요금 정보를 확인한다.
3. `needsRewrite: true`: 추측성·빈 방문 팁·중복 소개를 제거하고 실제 방문 판단에 필요한 정보만 남긴다.

## 한 글을 고치는 기준

- 제목의 질문을 첫 2~3문단 안에서 답한다. 장소 소개가 아니라 주차·예약·유모차·반려동물·비 오는 날 중 실제로 확인한 조건을 다룬다.
- 운영시간, 요금, 예약, 주차, 반려동물·접근성은 공식 출처와 확인일을 대조한다. 확인하지 못한 항목은 가능하다고 추정하지 않는다.
- 같은 시설 설명을 소제목마다 되풀이하지 않는다. 근거 없는 체류시간, 방문 후기, 인기·최저가·건강 효능은 쓰지 않는다.
- 기존 URL과 내부 링크·이미지·제휴 추적 링크는 유지한다. 수정한 뒤에는 대표 URL, 메타 설명, 구조화 데이터, 모바일 화면을 확인한다.

## 공개 전 확인

1. 원본 출처와 확인일을 기록했는가.
2. 사실·숫자·운영 정보가 원본과 일치하는가.
3. 다른 글과 같은 문장·소제목을 반복하지 않았는가.
4. 독자가 실제로 결정할 수 있는 정보가 있는가.
5. 공개 후 URL, canonical, 내부 링크, 이미지가 정상인가.

자동 검수 통과는 사실 확인 완료를 의미하지 않는다. 특히 외부 운영 정보가 변할 수 있는 글은 사람의 원본 대조 후에만 보완을 완료로 표시한다.
