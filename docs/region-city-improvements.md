# 지역 허브·시티투어 사진 개선

## 기존 구조와 선택

17개 `/region/[code]`는 행사 중심 제목·긴 소개, 문화행사를 기본 선택한 RegionContentFilter, 전국 행사 데이터가 전달되는 DateBrowser를 이어 붙인 구조였다. 행사 더보기가 자기 URL로 연결되는 곳도 있었다.

기존 데이터 접근 함수와 상세 URL을 유지하고 표시 계층을 종합 허브로 정리했다. 지역 제목 → 빠른 탐색 → 중복 없는 혼합 추천 8개 → 실제 데이터가 있는 분야별 4개 미리보기 순서다. 더보기는 기존 지역별 목록 또는 접힌 추가 목록이다. 사진 보유 항목을 우선하며 인기 순위라고 표현하지 않는다. 무료는 확정 `free`, 아이와/데이트는 기존 `isKid`·`audiences` 분류를 사용한다. 이번 주말 행사만 섞되 장소·시티투어의 운영/예약을 보장하지 않는다.

## 시티투어 사진

`galleryForStops`에 선택적 엄격 매칭을 추가하고 기존 `CoursePhotoGallery`를 재사용했다. 기존 여행코스 호출의 매칭 방식은 그대로다. 시티투어는 원본 노선 구분자와 경유지명을 읽고, 기존 관광지의 명칭·지역·주소·콘텐츠 ID를 대조한다. 제목 정확 일치와 행정지역이 맞는 관광사진 캐시를 우선하고, 부족하면 확인된 해당 관광지의 기존 TourAPI 대표사진만 사용한다. 지역명만으로 사진을 채우지 않는다.

대표 1장, 첫 본문 뒤 최대 2장, 세 번째 본문 뒤 최대 2장으로 분산한다. 관련 장소 링크의 중복 썸네일은 제거하고 주소·링크를 유지했다. 동일 URL(HTTP/HTTPS 통일)은 한 번만 표시한다. 사진 캡션에 장소와 출처를 표시하고, 촬영 월 00은 '촬영 월 미제공'으로 처리한다. 일부 코스의 사진은 현재 계절과 다를 수 있다.

20개 중 13개는 3~5장, 7개는 1~2장이다. 부산 4장, 인천 4장, 여수 5장, 여주 3장. 실제 관광지가 같은 이름인 경우에도 행정지역이 맞지 않으면 제외한다. 전수가 아니라 현재 캐시에서 확실히 연결한 범위다.

## SEO·성능·보존

- 17개 지역 및 기존 상세 URL/canonical 유지. 지역별 title/description은 실제 종합 허브 내용에 맞춰 변경하고 CollectionPage/ItemList/BreadcrumbList를 추가했다.
- 시티투어 Article/BreadcrumbList, 기존 title/description·운영정보·공식 링크·저장/공유 기능 유지. 이미지 메타데이터는 실제 노출 사진에 맞췄다.
- 기존 음식점·경유지 연결을 보존하고 같은 경유지 ID가 있는 발행 여행코스와 지역 허브를 연결했다.
- 방문자 요청 시 신규 공공 API 호출 0회. 정적 캐시 재사용, 지역 허브 ISR 1시간, 전국 행사 클라이언트 데이터 제거.
- 대표사진 우선 로드, 아래 사진 lazy loading, 명시적 aspect-ratio/fill/sizes, 최대 5장, 기존 unoptimized 전달 방식 유지. 새 이미지 API·수집 비용 없음.
- 공개 시티투어 사진 58개 URL 모두 HTTP 이미지 응답 정상. 서버가 HEAD를 거부하여 Range GET으로 검사했다. 헤더 보고 용량 총 17,353,506바이트(전체 코스 합집합), 최대 단일 원본 약 1.71MB. 이미지 리사이징 효과를 측정했다고 주장하지 않는다.

## 남은 제한

7개 코스는 확인 가능한 사진이 1~2장뿐이다. 숫자를 채우기 위한 넓은 매칭은 하지 않았다. 지역 추천은 현재 수집·발행된 데이터 기준이며 현장 운영과 예약은 공식 확인이 필요하다. 기존 의존성 보안 경고의 메이저 업그레이드는 이번 작업에 포함하지 않았다.

## 후속 모바일 탐색 정리

메인의 지역 바로가기는 `HomeRegionPicker`로 분리했다. 서울·경기·인천만 기본 표시하고 나머지 14곳은 더보기로 접는다. 지역 이름/정식 명칭 검색 시 일치하는 지역을 먼저 표시하며, 검색 결과가 없어도 전체 지역을 펼칠 수 있다. 17개 실제 링크는 HTML에 유지한다.

지역 허브는 `RegionHubFilter`에서 이번 주말 추천을 기본 표시하고 종류를 누르면 해당 패널만 보여준다. 모든 분야가 한꺼번에 길게 펼쳐지지 않는다. 문화행사의 세부 분야는 드롭다운으로 선택하며 관련 카드와 기존 분야별 전체보기 링크만 표시한다. 기존 `#places`·`#kids` 등 해시도 필터 선택으로 복원한다.

추가 변경 파일: `components/HomeRegionPicker.tsx`, `components/HomeExplorer.tsx`, `components/RegionHubFilter.tsx`, `app/region/[code]/page.tsx`. 브라우저에서 기본 3개/확장 17개, 서울 검색, 부산광역시 별칭 검색, 미일치·초기화, 서울 이동, 단일 패널 전환, 무료 전시 선택을 검사했다.
