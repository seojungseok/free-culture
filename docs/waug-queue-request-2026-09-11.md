‘주말에 뭐하지’ 와그 제휴 콘텐츠의 글 작성·발행 예약을 정리해줘.

이번 작업은 처음 전달한 링크의 남은 미작성 장소와 아래 영남권 106개 상품을 기존 대기열에 통합하고, 하루 총 20개 일정으로 예약하는 작업이다.

지금 전체 글과 이미지를 일괄 생성하거나 즉시 발행하지 마. 홈페이지 디자인 등 다른 작업은 진행하지 말고, 예약에 필요한 데이터 정리와 자동 실행 준비만 해줘.

[1. 기존 글과 신규 링크 통합]

기존 발행 글, 작성 완료 초안, 예약 글, 미작성 상품을 먼저 확인해줘.

- 이미 작성한 장소는 신규 작성 대상에서 제외해줘.
- 작성 완료된 미발행 초안은 재작성하지 말고 검수·이미지 보완 후 발행하도록 유지해줘.
- 이미 예약된 글은 중복 예약하지 마.
- 처음 전달한 링크의 미작성 장소와 이번 106개 목록의 신규 장소를 하나의 대기열로 합쳐줘.
- 같은 장소의 일반권·오후권·야간권·어린이권·패키지는 실제 조건을 비교해 대표 장소 글에 연결해줘.
- 기존 글에 새로운 이용권만 추가하면 되는 경우에는 보완 대상으로 관리하고 새 글을 만들지 마.

상품 ID와 실제 장소·지점을 함께 비교해 중복을 판단해줘. 기존 대기열을 초기화하거나 글을 삭제하지 마.

[2. 제휴링크 저장과 사용]

아래 106개 원본의 장소명과 제휴링크를 빠짐없이 프로젝트의 영구 데이터에 저장해줘.

상품 ID, 실제 지역, 장소, 지점, 내 제휴링크, 연결 글, 작성 상태, 이미지 상태, 예약일, 제외 사유를 관리해줘.

글의 이용권·구매 버튼에는 반드시 내가 제공한 해당 상품의 https://www.waug.com/r/… 주소를 사용해줘.

제휴코드의 대소문자를 보존하고 일반 와그 상품 주소로 교체하지 마. 상품 조사용 URL과 실제 구매 버튼용 제휴 URL을 구분해 저장해줘.

기존 정상 제휴링크가 있는 동일 상품은 새 링크를 이력으로 보관하고, 임의로 대표 링크를 교체하지 마.

[3. 지역 분류 및 제외]

이번 자료는 부산·대구·울산·경북·경남이 섞인 영남권 목록이다. 전체를 경북으로 등록하지 말고 실제 소재지 기준으로 분류해줘.

중복·커밍순·판매 종료·이용기간 종료·실외 물놀이 상품은 작성·발행 대상에서 제외해줘.

실내외 혼합 상품이나 판매 상태가 불명확한 상품은 확인 대기로 분리해줘. 온천·사우나·케이블카·루지·야외 방탈출은 이름만 보고 제외하지 마.

기간형 상품은 예정된 발행일에도 이용 가능한지 확인해줘. 제외한 항목은 재등록 방지용 관리 이력을 남겨줘.

[4. 하루 총 20개 작성·발행 예약]

한국시간 Asia/Seoul 기준으로 기존 예약분과 이번 신규 대기열을 합쳐 하루 총 20개 발행 일정으로 편성해줘.

신규 작성도 하루 최대 20개로 예약하고, 이미 작성된 초안이 있으면 해당 날짜의 발행분에 우선 활용해줘. 작성된 글을 다시 생성하지 마.

- 지역별·목록별로 각각 20개가 아니라 사이트 전체 합계 하루 20개다.
- 이미 당일 발행한 글과 기존 예약 글도 합계에 포함해줘.
- 경기도와 영남권 등 지역·테마를 균형 있게 섞어줘.
- 기존 예약일은 가능한 한 유지하고 빈 일정에 새 대상을 배정해줘.
- 오래 기다린 장소가 계속 밀리지 않도록 해줘.
- 검수가 끝난 글이 부족하면 미완성 글로 숫자를 채우지 마.

지금은 원본 등록·중복 정리·상태 분류·일정 편성·예약 실행 연결까지만 진행해줘. 예약된 작성 시점에 실제 조사와 글·이미지 생성을 실행해줘.

[5. 예약 실행 시 글 작성 기준]

각 장소의 내 제휴링크 상품 페이지, 시설 공식 정보, 우리 홈페이지의 공공데이터를 확인한 뒤 작성해줘.

국내외 블로그·여행 사이트·유튜브에서 조사한 정보 중심 글쓰기 원칙을 이어서 적용하고, 글 구성은 장소별로 자체 판단해줘.

독자가 장소를 이해하고 방문을 준비하는 데 도움이 되는 정보를 제공한 뒤, 자연스럽게 내 제휴링크로 이용권을 확인하도록 연결해줘.

허위 방문 경험, 확인되지 않은 시설·가격·할인 정보, 반복적인 광고 문구를 사용하지 마. 변동 정보는 출처와 확인일을 관리해줘.

제휴 고지는 명확히 표시하고 관련된 기존 발행 글의 내부링크를 활용해줘. 아직 공개되지 않은 예약 글로 내부링크를 만들지 마.

[6. 각 글에 서로 다른 이미지 최소 3장]

신규 작성 글과 미발행 초안·예약 글은 대표 썸네일을 포함해 서로 다른 이미지 최소 3장을 갖추도록 해줘.

기본 구성:
- 대표 썸네일 1장
- 본문 이미지 2장 이상

대표 썸네일은 테스트에 성공한 OpenAI 이미지 생성 API로 장소당 한 장 제작해줘. 이미 완성된 정상 썸네일은 재사용해줘.

장소명과 글에 맞는 짧고 자연스러운 한글 문구를 넣고, 한글 깨짐·오탈자·어색한 줄바꿈을 검수해줘. 필요하면 배경을 생성한 뒤 코드로 한글을 합성해줘.

실제로 없는 시설이나 풍경을 해당 장소의 실제 촬영 사진처럼 만들지 마. 정확한 재현 근거가 부족하면 글의 주제에 맞는 일러스트·그래픽형으로 제작해줘.

본문은 사용 가능한 와그 공식 사진과 우리 홈페이지의 공공정보·관광사진을 우선 활용해줘. 같은 사진을 크롭하거나 색만 바꾼 이미지를 여러 장으로 계산하지 마.

사진이 부족하면 글에 맞는 일러스트를 생성해 보완할 수 있지만, 다른 장소 사진으로 수량을 채우지 마. 지도·가격·시간표 등 정확해야 하는 정보는 생성 이미지에 임의로 그려 넣지 마.

사진은 해당 내용 옆에 나눠 배치하고 글 맨 위에 세 장을 몰아넣지 마.

와그 사진의 식별 가능한 사람 얼굴은 임의로 사용하지 말고 사람이 없는 시설·풍경 사진을 우선해줘. 편집 권한이 확인되지 않은 사진을 생성 API에 넣어 변형하지 마.

실제 공공사진을 활용한 경우 필요한 출처는 오른쪽 아래에 작고 읽을 수 있게 표시해줘. 공공사진을 사용하지 않고 새로 생성한 이미지에는 ‘경기도·공공누리’ 같은 해당 없는 출처를 붙이지 마.

썸네일은 최종 1200×630px로 만들고 모바일·PC·외부 공유에 같은 파일을 활용해줘. 웹용으로 최적화해 업로드하고 대표·목록·OG 이미지에 연결해줘.

검증된 이미지 3장을 확보하지 못한 글은 보완 대기로 관리해줘. 이미 발행한 글은 이번 작업에서 일괄 재작성하거나 이미지를 다시 생성하지 마.

[7. 컴퓨터를 꺼도 자동 실행]

예약 시각이 되면 내 컴퓨터 전원이 꺼져 있거나 코덱스가 종료된 상태에서도 서버에서 다음 과정이 실행되어야 한다.

상품 확인 → 장소 조사 → 글 작성 → 썸네일 생성 및 본문 이미지 확보 → 검수 → 웹용 최적화 → 영구 저장소 업로드 → 글 연결 → 예약 발행 → 배포

기존 GitHub Actions와 서버 자동화의 구현 상태를 확인하고 누락된 부분만 연결해줘. 로컬 파일이나 로컬 로그인 세션에 의존하지 마.

서버 실행 시간이 부족하면 단계를 나누고 상태를 저장해서 다음 실행에서 이어가도록 해줘.

중복 실행 시 글·이미지를 다시 생성하지 않도록 하고, 재시도 횟수에 상한을 둬줘. API 키는 서버 비밀값으로 관리하고 로그에 노출하지 마.

이미지 생성 모델·품질 설정과 예상 비용을 기록해줘. 이번 예약 정리 과정에서 전체 대기열을 테스트 명목으로 생성하지 마.

예약 글은 공개 시각 이전에 목록·검색·사이트맵에 노출하지 마.
