# 겨울 먹거리 스튜디오 배너 · 2026-11-13

사용자가 승인한 자연스러운 v4 음식 사진을 바탕으로 실내 스튜디오 연출을 추가한 v5 편집이다. 음식의 모양·속 재료의 양·자연스러운 조리 흔적은 유지하고, 확산광·반사광·배경색·그릇 배치와 올라오는 김을 조정했다. 판매처 원본 사진은 수정하지 않았다. 배너 사진은 특정 브랜드 제품의 실물 촬영 사진으로 표시하지 않으며, AI 조리·상차림 예시임을 밝힌다.

## 시각 구성

- 호빵: 차분한 자주색 배경과 아이보리 접시.
- 팥 붕어빵: 청록색 배경, 크라프트 종이와 식힘망.
- 꿀호떡: 따뜻한 코코아색 배경, 아이보리 접시와 유산지.
- 고구마: 짙은 녹색 배경, 베이킹 트레이와 종이. 연결 상품은 생고구마이고 군고구마는 조리 예시다.
- 고기만두: 회청색 배경과 푸른 테두리 접시.
- 떡볶이: 테라코타색 배경과 흰 그릇.

모든 최종 자산은 1800×600px, 3:1 WebP다. 사진을 자르거나 늘리지 않고 원래 비율로 표시한다. 데스크톱에서는 사진과 문구를 좌우로 배치하고, 작은 화면에서는 사진 아래에 상품명·가격·구매 버튼만 둔다. 하단 상품 탭 줄을 제거했다. 작은 화면은 자동 전환 없이 좌우 버튼과 스와이프로 탐색하며, 조작 영역은 최소 44px이다.

## 수집 전환

배포 직후에는 UI에서 검토한 시각이 기록된 공개 스냅샷을 사용한다. 이 스냅샷은 가장 이른 확인 시각으로부터 6시간 후 만료되며 시각을 자동으로 연장하지 않는다. 새 버전의 정기 수집이 완료되면 그 결과를 우선하고, 품절·이름 변경·이미지 불일치로 제외된 상품을 이전 스냅샷으로 복구하지 않는다. 정기 수집은 기존 호출 예산과 공유 잠금을 사용한다. 방문자 요청에서 상품 API를 호출하지 않는다.

새 상품도 검토한 원본 UI 제휴 URL을 재사용한다. 기존 피드가 15분 이내여도 이전 캠페인 버전이면 새 수집을 건너뛰지 않는다.

NAS의 일회성 읽기 전용 조회는 별도 사용자 승인을 받았다. 자동 수집 잠금으로 처음에는 API 호출 전 종료됐고, 기존 자동 수집 종료와 잠금 파일 부재를 확인한 뒤 카테고리 목록 1회를 조회했다. 이후 검증한 실제 카테고리 ID로 토스 UI에서 6개 상품을 확인하고 링크를 발급했다. 비밀키를 출력하거나 새 인증을 발급하지 않았다. 일회성 작업의 예약 활성화는 해제했다.
