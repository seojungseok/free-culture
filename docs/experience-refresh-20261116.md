# 체험·교육 자료와 모집 상태 재점검 (2026-11-16)

## 수집과 공식 안내 대조

- 승인된 기존 API를 끝 페이지까지 다시 수집했다. 농어촌 체험 1,261행(2회), 청소년 프로그램 3,575행(4회), 평생학습 강좌 29,637행(30회), 합계 34,473행이다. 각 스냅샷의 `refresh.complete`가 참이다.
- 활동 종료일이 남아 있는 청소년 프로그램 117개는 상세 API도 전부 다시 조회했다. 성공 117, 실패 0, 미조회 0이다. 공식 e청소년 목록에서는 프로그램 ID·제목·기관을 일치시켜 117개 모두 모집 상태를 확인했다.
- 청소년 원자료의 상태는 상시/접수기간 내 86, 접수예정 2, 마감 14, 모집 상태 미확인 15였다. 이 수치는 체험·교육 주제 선별 전 원자료 수다. 순수 상담 등은 체험 목록에서 별도 제외한다.
- 과학관 두 공식 홈페이지의 교육·모집 안내도 갱신했다. 모집 시작·종료 시각과 회차 시간을 구분해 저장한다.
- 추가 청소년 프로그램 API(공공데이터포털 15132855)는 기존 인증키로 HTTP 403이었다. 사용 가능한 모든 API를 확보했다는 뜻은 아니다. 추가 승인이나 인증 우회 없이 기존 승인 API와 공개된 공식 안내를 대조했다.

## 현재 모집, 마감, 회차

- 목록, 관련 글, 사이트맵, RSS, 상세 신청 버튼이 `programmeAvailability`를 공유한다. 활동 종료·모집 마감·명시적 취소·불명확한 모집일은 현재 모집 목록에서 제외한다.
- 공식 청소년 목록의 확인 결과가 30시간을 넘으면 확인 전까지 현재 모집에서 제외한다. 일반 날짜 자료는 48시간, 체험마을은 72시간의 확인 유효기간을 적용한다. 수집 실패로 오래된 모집 안내가 계속 최신처럼 표시되지 않는다.
- 검수 시 현재 접수기간에 해당하는 체험·과학관 프로그램은 57개, 문화·취미 강좌는 396개였다. 잔여석을 확인한 숫자는 아니다. 접수예정은 별도 필터로 분리한다.
- 날짜별 운영·모집 정보를 제공하지 않는 체험마을 1,261곳은 예약 문의용 별도 목록으로 안내한다. 현재 접수 중인 날짜형 프로그램 수에 합산하지 않는다.
- 동일 이름·기관·장소·대상·비용·강좌 내용의 시간/요일 차이는 한 글의 회차 표로 묶는다. 장소나 참여 조건이 다른 강좌는 합치지 않는다. 수정 전 시간과 철회된 등록자료가 새 회차로 되살아나지 않도록 같은 기간의 최신 등록 버전을 우선한다.
- 강좌 원자료 2,832개는 2,812개 글로, 과학관 원자료 18개는 11개 글로 통합됐다. 원래 ID는 대표 글로 영구 이동해 기존 URL을 보존한다. 이전 회차는 펼쳐 보는 기록으로 남으며 현재 모집 목록에는 나오지 않는다.
- 문제로 제보된 멘토링(384587)은 공식 모집 마감이다. 현재 목록·신청 버튼에서는 제외하고 기존 상세 주소에 마감 상태를 안내한다. 겨울방학 꿈모닝(384687)은 12월 15~28일 접수예정이며 현재 신청으로 표시하지 않는다.

## 사진과 읽기 화면

- 작은 e청소년 썸네일 매개변수만 제거해 같은 첨부 파일의 원본 사진을 받는다. 신규 사진 148개 저장이 성공했으며 신규 다운로드 실패는 0이었다. 기존 실패 항목의 재시도 대기와 출처 확인은 유지한다.
- 청소년 이미지 102개를 시각 검토했다. 실제 활동 사진, 안내 포스터, 기관 로고·공통 그림·사이트 화면을 구별하고 압축 파일 해시로 검토 결과를 연결했다. 알려진 로고·공통 그림 25개 프로그램은 주제 이미지로 대체한다.
- 사진이 없거나 작거나 실패한 경우 사이트가 이미 수집한 TourAPI 사진과 검토한 공식 활동 사진을 주제별로 재사용한다. 화면의 글씨는 HTML로 표시하고 ‘주제 이미지’ 배지와 원본 출처, 해당 프로그램 현장 사진이 아니라는 설명을 붙인다.
- 이미지는 로컬 WebP로 제공하며 대체 이미지도 로컬 파일이다. 공식 포스터는 전체를 읽을 수 있게 잘림 없이 표시하고 크게 보기 링크를 제공한다.
- 모바일에서 제목·본문·신청 안내·회차 표가 한 열로 배치된다. 접수 종료 글에는 종료 안내를 먼저 표시한다. 원자료의 깨진 물음표 목록 기호 정리와 사실 기반 검색 제목·본문 규칙을 유지한다.

## 재발 방지와 검증

- 매일 갱신 과정의 상세 40/사진 20~30개 같은 작은 고정 처리 수 제한을 제거했다. 현재 자료 전체가 처리 대상이며 실제 요청에는 기존 간격·재시도·실패 보존 규칙을 적용한다. 방문자 요청에서는 외부 API를 호출하지 않는다.
- `scripts/programme-availability.test.mjs` 및 관련 원자료·사진·본문·검색 메타 검사 41개 통과. 일일 수집 워크플로에도 모집·회차·본문 검사를 추가했다.
- 운영 빌드와 `scripts/verify-programme-current.mjs`로 모든 상세 글, 이전 ID 이동, 지역별 목록, 현재/예정 필터, 이미지 응답, RSS와 사이트맵을 확인한다. 상세 검사는 원자료 기록까지 포함하고 공개 나스에서는 대표 글과 실제 배포 버전을 추가 확인한다.
- 실제 배포 확인은 DSM 기존 동기화 작업의 정상 종료와 공개 `/api/site-status`의 커밋 일치, 공개 화면 확인을 모두 사용한다.
- 최종 로컬 운영 검사: 상세 글 4,202개, 이전 주소 27개의 HTTP 영구 이동, 목록의 전체 페이지, 이미지 206개, RSS·사이트맵을 합쳐 4,543건 통과, 실패 0. 운영 빌드는 정적 페이지 1,471개 생성을 완료했다. 390px 상세 화면에서 사진 로딩과 두 시간대 표시, 가로 넘침 없음을 확인했다.
