# 준비 가이드 제휴 동선 업데이트 · 2026-11-11

## 변경 범위

- 기존 준비 가이드 44개의 slug, 공개 상태, 제목, 설명, 본문 데이터, 사진과 기존 제휴 URL을 보존했다. 다른 카테고리 데이터와 메인 토스 고정 상품 구성은 변경하지 않았다.
- 애드센스 계정 메타, ads.txt의 판매자 등록, 개발용 광고 자리 표시를 제거했다. `/ads.txt` URL은 안내 주석과 함께 유지했다. 개인정보처리방침의 광고 설명을 실제 제휴 운영에 맞췄다.
- 사진 아래 44px 이상의 `+` 준비물 버튼을 추가했다. 안내 열기·닫기, Escape와 키보드 포커스 복귀를 지원한다. 상품 연결이 없는 재료도 역할을 확인할 수 있다.
- AI 사진과 실제 상품의 외형이 같다고 표시하지 않는다. 상품이 확인된 경우에만 원본 제휴 URL을 사용하며, 실제 판매처 사진과 포장 옵션을 별도로 보여 준다.
- 꽃게탕의 꽃게를 필수 주재료로 첫 번째에 표시했다. 기존 조리 안내의 2인분 300~400g과 판매 포장을 구분했다. 재료 바로가기와 체크리스트를 조리 순서보다 앞에 배치했다.
- 기존의 같은 요리 글 6개에도 공개된 재료 가이드의 상품을 연결했다. 관계없는 상품을 일괄 배치하지 않았다.

## 상품 검토

기존 `coupangFetch`와 GitHub 공용 CAS 제한기를 통해 검색 요청 8회, 상품 조회 8개를 순차 실행했다. 요청당 limit=1, 시작 간 추가 대기 7.1초, 실패 시 중단 방식이다. 캐시 우회 호출, 브라우저 상품 방문, 자동 재시도, 신규 정기 수집 작업은 추가하지 않았다.

API가 반환한 상품명·규격·옵션과 반환 사진을 대조한 꽃게, 20cm 양수냄비, 손질 오징어 3개를 기존 6개 글의 빈 연결 7곳에만 추가했다. 후보 기록의 reviewed 승인과 사유를 함께 저장했다. 대량 묶음 등 추가 확인이 필요한 4개 후보는 승인하지 않았고, 일치하지 않은 국물 후보 1개는 제외했다. 판매 가능 여부·실시간 가격·배송 조건을 보장하지 않으며 최종 옵션은 판매처에서 확인한다.

## 측정

기존 `/api/affiliate/events` 수집기를 그대로 이용한다.

| placement | 위치 |
| --- | --- |
| prep_image | 사진 아래 상품 안내 |
| prep_checklist | 재료 체크리스트 |
| prep_product_list | 같은 요리 글의 재료 목록 |

버튼 50% 이상 노출 시 마운트당 1회 `affiliate_impression`, 링크 클릭 시 `affiliate_click`을 전송한다. Beacon 실패에만 keepalive fetch를 사용한다. 수집 항목은 시각·이벤트·제휴사·배치·페이지 경로·숫자 상품 ID이며 원본 URL·제휴 토큰·이름·연락처는 기록하지 않는다. 팝업 재열기나 체크 해제 후에는 새 노출 이벤트가 생길 수 있으므로 고유 방문자 전환율로 해석하면 안 된다.

NAS 집계 예시:

```sh
node scripts/report-affiliate-events.mjs --input runtime/sharelink/events --from 2026-11-11 --to 2026-11-17
```

날짜는 한국 시간의 하루 전체다. 클릭 수와 노출 대비 클릭 이벤트 비율은 확인할 수 있으나 실제 구매·확정 수수료는 쿠팡 파트너스 보고서에서 별도로 확인해야 한다.

## SEO와 검증

기존 제목·설명·canonical을 유지하고 Article의 식별자와 사이트 관계, 본문에 표시된 재료 정보를 보완했다. Breadcrumb 명칭을 실제 메뉴에 맞췄다. 확인되지 않은 Product 가격·재고·별점이나 Recipe 구조화 데이터는 추가하지 않았다.

- 단위·수집기 통합·보존 검사 15개 통과.
- 운영 빌드의 타입 검사와 정적 페이지 생성 통과.
- `node scripts/prep/verify-affiliate-render.mjs http://127.0.0.1:3186`: 기존 44개 글, 검토된 47개 상품 연결, 상품 사진 3개, canonical·Article·Breadcrumb와 애드센스 제거 검사 통과. 제휴 목적지 방문은 0회다.
- 320px·390px 모바일에서 가로 넘침, 44px 버튼, 안내 열기·닫기, 미연결 재료 안내, Escape 포커스 복귀, 체크 저장·복원을 확인했다.
- 1280px 데스크톱에서도 가로 넘침과 안내 열기·닫기를 확인했다. 실제 브라우저 노출 이벤트의 로컬 파일 저장과 합성 클릭의 HTTP 204 저장을 확인했다. Next.js 로컬 Origin은 `localhost`를 사용했으며 운영 도메인 검증 규칙은 변경하지 않았다.

검색 노출·조회수·클릭·매출 증가를 검증한 결과는 아니다. 변경 이후 같은 기간의 페이지별 노출과 클릭 이벤트, 쿠팡의 확정 실적을 구분해 평가한다.
