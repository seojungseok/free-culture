# 지역 카드와 내부 상세 페이지 전환

2026-11-14 사용자 수정 요청: 문화행사처럼 지역별 카드에서 고르고, 내용은 홈페이지 안에서 읽고, 신청할 때 외부 공식기관으로 이동한다.

## 자료

- 농어촌 API 전체 1,261곳을 수집하고 체험 프로그램·시설·도로명주소·전화·좌표·제공 사진·원자료 기준일을 저장했다.
- 청소년 API 전체 3,575건을 대조한 진행·예정 118건에 상세 조회 `getVacationProgrmInfo`를 추가 실행했다. 118건 모두 상세 조회에 성공했다. info1·info2 본문 전체를 문단으로 정리하고 주소·전화번호를 추가했다. `managernm` 등 별도 담당자명 필드는 복제하지 않는다.
- 과학관은 공식 교육표 2곳에서 현재 14개 일정을 확인한다. 과거 상세 URL을 보존할 수 있도록 목록에서 제외된 기록도 남기고 검색 색인에서는 제외한다. 교육표 순번으로 URL이 바뀌지 않도록 제목·교육일·예약 주소로 ID를 만든다.
- 기존 TourAPI 캐시에서 명칭과 지역이 같고 좌표 또는 주소까지 일치한 농촌 체험마을 121곳을 대조했다. 다른 지역의 동명 마을이나 위치가 다른 곳의 사진을 쓰지 않는다.
- 국립중앙과학관의 소개·주소·전경 사진은 기존 승인 TourAPI를 2회 조회해 보강했다. 학교 프로그램에 과학관 전경을 사용할 때 전경임을 명시한다.
- 제공기관 사진은 허용된 공공 이미지 호스트에서 받아 최대 900px WebP로 저장한다. 사진이 제공되지 않은 프로그램의 목록 카드에는 안내 그래픽을 사용한다. 내부 상세에는 큰 사진 대용 그래픽을 넣어 본문을 밀어내지 않는다.

## 사이트 구조

- `/experiences`: 분야·지역 선택과 실제 체험 카드 목록. 안내 배너 3개로 대체하지 않는다.
- `/experiences/family`, `/experiences/science`, `/experiences/rural`: 분야별 카드와 지역·시군구·검색 필터.
- `/experiences/region/[area]`: 17개 시도별 고유 제목과 지역 체험 카드.
- `/experiences/[kind]/[id]`: 활동 본문, 체험 목록, 일정·대상·비용, 주소·전화·시설, 출처, 관련 체험. 카드의 주 링크는 이 내부 상세 URL이다.
- `/classes/detail/[id]`, `/accessible-travel/[id]`: 앞서 추가한 강좌와 편의정보도 내부 상세로 연결한다.

홈의 예전 3개 안내 상자는 실제 체험 카드 미리보기와 지역 바로가기로 교체한다. 내부 상세의 신청 버튼과 전화 문의, 지도·출처 링크만 기관별 외부 경로를 사용한다. 청소년 신청처는 기관 전화번호와 활동명으로 필터링된 e청소년 공식 검색을 제공한다. 사이트에서 실제 예약이 완료되는 것처럼 표시하지 않는다.

## 검색·속도·갱신

상세별 고유 title·description·canonical·OpenGraph와 본문과 일치하는 WebPage, Event/EducationEvent/TouristAttraction 또는 Course, Breadcrumb를 제공한다. 지역과 상세 사이에 내부 링크를 둔다. 검색 조건 URL은 noindex,follow이며 내용이 충분한 상세와 지역만 사이트맵에 포함한다. 종료된 페이지를 새 행사로 표시하지 않는다. 단순 조회시각을 SEO의 수정일로 만들지 않는다.

목록은 24개씩 서버에서 렌더링하며 전체 원자료를 방문자 브라우저에 전송하지 않는다. 일부 대표 상세만 사전 생성하고 나머지는 요청 시 생성해 1시간 캐시한다. 카드의 자동 상세 prefetch를 끄고, 사진은 로컬 WebP와 고정 비율·지연 로딩을 사용한다. 방문자의 조회로 외부 기관 API를 호출하지 않는다.

일일 작업에 청소년 상세 최대 40건(7일 재확인), 장소 대조, 새 사진 최대 30개 캐시를 연결한다. 원자료 수집 실패는 기존 캐시와 상세 URL을 보존한다. 농어촌·청소년·과학관과 강좌·편의정보에서 제외된 기존 상세 기록도 보관한다. 기존 문화행사·준비가이드·제휴 추적 URL은 변경하지 않는다. 쿠팡 API는 호출하지 않는다.

## 검증 상태

자료 정규화·상세 보존·사진 매칭·고유 ID·기존 준비가이드 보호 검사 32건과 타입 검사가 통과했다. 전체 빌드는 정적 1,461개 페이지를 생성했다. 실제 체험 상세 1,397개 전체와 지역·필터·강좌·편의정보 일부를 포함한 로컬 HTTP 검사 1,485건이 모두 통과했고, 이 검사에서 색인 허용 상세 741건의 제목·설명 중복과 사이트맵 연결도 확인했다. 기존 안내·준비가이드 HTTP 검사 59건도 통과했다.

PC에서 지역 선택과 카드 → 내부 상세 → 공식 신청처 동선을, 모바일 390px에서 지역·시군구 필터와 2열 카드를 확인했다. 사진 166개를 WebP로 캐시했다. 운영 배포와 공개 사이트 검사는 별도 결과로 기록하며 검색 노출·방문자 증가는 아직 측정하지 않았다.
