## 방문자가 보는 변화

코스에 장소별 운영·예약 조건과 정확한 상세 링크를 표시한다. 목록에 없는 공식 경유지는 코스 안에서 공식 소개를 읽을 수 있다. 주소·좌표가 확인되지 않은 곳은 지도 검색을 유지한다.

행사 상세에 공식 관람·참여 정보를 별도 표시하고 원문 링크·개별 확인 날짜를 함께 제공한다. 국립민속박물관 '저녁 괴담회'는 산책·강연 시간표, 성인 대상, 회차당 20명, 신청 기간, 남은 회차의 마감 현황까지 대조했다. 이는 확인 당시의 상태이며 신청 직전 원문을 확인해야 한다.

원문의 행사명과 회차 날짜를 대조한다. 기관·매표소의 일반 운영시간, 내비게이션 '이용안내', 다른 행사 소개는 행사 조건으로 쓰지 않는다. 경기어린이박물관 프로그램은 API 종료일과 공식 안내 종료일이 달라 보강 조건을 보류했다. 원래 행사 URL은 보존했다.

## 갱신과 한도

GitHub 일일 작업에 공식 코스 ID 재점검, 장소별 조건 저장, 문화행사 설명·원문 보강을 추가했다. 코스는 30일, 문화행사는 7일 단위로 미확인·오래된 항목부터 점검한다. 공식 링크가 바뀌면 원문 점검도 다시 수행한다.

문화행사 요청은 시작 간격 최소 650ms로 직렬 제한한다. 짧은 요청 제한은 Retry-After를 반영해 제한적으로 재시도하고, 일일 제공기관 한도는 기존 정보를 보존하며 다음 실행으로 이월한다. 인증·형식 오류는 실제 실패로 남긴다. 모든 시도를 예산에 포함한다.

TourAPI의 `detailCommon2`는 오늘 제공기관의 요청 한도 응답으로 추가 장소 조건 수집이 보류됐다. `detailInfo2`와 `searchKeyword2`는 정상 응답해 경유지 ID 대조에는 사용할 수 있었다. 같은 실패 엔드포인트를 반복 조회하거나 인증키를 바꾸지 않았다.

일반 TourAPI 수집 예산은 월요일 일일 170 + 주간 830 = 최대 1,000회, 그 외 일일 최대 350회다. 이는 자체 보수적 예산이며 제공기관 제한이 우선한다. 방문자 페이지에서는 API를 호출하지 않는다. NAS는 기존 매시간 :15 동기화 작업을 사용한다.
