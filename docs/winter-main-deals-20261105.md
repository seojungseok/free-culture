# 토스 겨울 먹거리와 하루특가 (2026-11-05)

- 메인 기획전은 어묵, 컵라면, 삼겹살, 순대, 블랙커피 5개를 고정한다. 방문자가 보는 상품 사진과 원본 제휴 링크는 같은 피드 항목에서 가져오며 상품명과 ID가 정확히 일치해야 한다. 품절되거나 확인할 수 없는 상품을 다른 상품으로 자동 교체하지 않는다. 매일 바뀌는 특가 목록과 분리한다.
- 메인에는 사용자가 요청한 기존의 넓은 음식 배너 방식으로 3:1 AI 음식 연출 사진을 사용한다. 작은 상품 사진 카드는 메인에서 제거했다. 실제 상품명·구성·토스 링크는 검증된 피드 항목과 고정 ID로 연결하며 AI 조리 예시임을 고지한다. 특가 레일은 판매처 실제 사진을 사용한다.
- 내장 imagegen 생성 프롬프트: 자연스러운 실제 음식사진 같은 조명·질감, 왼쪽 문구 여백, 가운데~오른쪽 음식 배치, 과한 증기·플라스틱 광택·로고·글자 제외. 개별 장면은 유부 없는 어묵꼬치 국물, 무상표 컵라면, 삼겹살 구이, 순대와 내장 접시, 블랙커피이다. `public/affiliate-images/toss-main-{fishcake,ramen,pork,sundae,coffee}-natural-20261105.webp`, 2172×724.
- 할인과 하루특가를 구분한다. 확인된 종료 시각이 있는 유효 특가에만 오늘의 특가 표시를 사용한다. 피드가 6시간 이상 오래되거나 제휴 링크가 토스 도메인이 아니면 숨긴다.
- 전 페이지 먹거리 특가 목록은 0보다 큰 토스 표시 할인율과 미래 종료 시각이 확인된 상품만 사용하고 별도 광고 문구를 표시한다. 방문 전 체크리스트가 있는 상세 페이지는 체크리스트 바로 앞에 배치한다. 토스 피드는 서버 예약 작업으로 갱신되며 방문자가 상품 API를 호출하지 않는다.
- 할인율은 토스 표시 기준으로, 다른 판매처와 비교한 최저가나 판매 순위를 의미하지 않는다. 구매 성과 개선은 실제 노출 후 측정해야 한다.
