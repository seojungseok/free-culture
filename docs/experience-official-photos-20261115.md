# 체험 카드 공식 안내 이미지 보완

사용자 화면의 베이지색 안내 그림은 API에 사진 필드가 없을 때 표시한 기본 그래픽이었다. 공식 e청소년 게시물에는 사진이 있는 사례를 확인해 프로그램 사진 수집을 별도로 연결했다.

- 공식 공개 검색 페이지의 프로그램 ID·전체 제목·운영기관이 모두 일치할 때만 안내 이미지를 채택한다. 특수문자가 포함된 제목은 제목의 대표 한글 단어로 최대 한 번 추가 검색하되 같은 세 조건을 다시 대조한다.
- 공식 안내 이미지 70개를 확인해 로컬 WebP로 저장했다. 프로그램 활동 사진과 기관 로고가 섞여 있어 모두를 행사 포스터라고 표시하지 않는다. 출처와 공식 게시물 링크를 내부 상세에 함께 제공한다.
- 2026-11-15 00:10 KST 기준 진행·예정 청소년 프로그램 79건 중 69건에 공식 안내 이미지를 표시할 수 있다. 나머지 10건은 검증된 사진을 확보하지 못했으므로 ‘공식 사진 미제공’으로 표시한다. 종료된 프로그램의 상세와 확보한 사진은 보존한다.
- 스크린샷의 대학생 학습 멘토링, AI리터러시 교육, UP&DOWN 아프리카 음악 체험은 모두 공식 이미지가 연결됐다. 일부 원본은 작은 사진이라 내부 상세에서 원본 이상으로 무리하게 확대하지 않는다. UP&DOWN 원본의 상하 반전은 확인한 원본 바이트의 SHA-256이 일치할 때만 180도 보정한다.
- 공개 페이지가 요구하는 익명 로드밸런서 쿠키는 실행 중 메모리와 발급한 호스트 안에서만 사용한다. 키·쿠키·세션 토큰은 콘텐츠와 로그에 저장하지 않는다. 다른 호스트나 허용하지 않은 경로로의 리디렉션은 차단한다.
- 일일 갱신에 공식 사진 최대 20개 대조와 7일 재확인을 추가했다. API 목록 갱신이 동일 프로그램의 확보된 사진을 지우지 않도록 보존한다. 실패하면 기존 사진을 유지한다.

검증: 사진 매칭·오류 보존·기존 체험 관련 단위 검사 19건, 전체 프로덕션 빌드, 로컬 사진 HTTP 검사 74건과 지역·상세·SEO HTTP 검사 81건을 통과했다. 운영 배포 결과는 별도 공개 검증 보고서에 기록한다.
