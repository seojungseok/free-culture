- 사용자 추가 요청을 반영해 광고는 **필수정보 바로 다음의 전체 폭 가로 영역**에 배치한다. PC의 우측 설명 칸 안에 삽입하지 않는다. 모바일에서는 사용자 최종 요청에 따라 **포스터 → 광고 → 제목·필수정보 → 상세 안내** 순이다. HTML 읽기 순서도 동일하다.

- 포스터는 전체 비율을 보존하고 확대 링크를 제공한다. 관람·신청, 프로그램, 장소·주변, 질문, 출처에 바로 갈 수 있다.

- `시간: 80분` 같은 소요시간과 실제 시작 시각을 구분한다. 각 사실의 출처와 확인 시각을 저장한다. 단순 재확인은 사이트맵의 내용 수정일을 바꾸지 않는다.
- 이미 소개글이 있는 행사도 관람 사실을 보강할 수 있다. 공식 페이지가 부족하면 문화포털의 행사 ID별 공개 상세를 같은 일치 검사로 확인한다. 유료 AI와 상품 API는 이 정보 수집에 사용하지 않았다.

## 검색

- 공연명과 실제 지역·분야를 사용하는 고유 제목, 80자 이내 설명, canonical과 일치하는 OG·Twitter 정보를 사용한다.
- `Event`와 화면의 경로에 맞는 `BreadcrumbList`를 제공한다. 단일 날짜와 한 회차 시각이 확인될 때만 `+09:00` 시작 시각을 표시한다. 여러 회차나 시간 미확인 행사는 날짜만 쓴다.
- 확인된 무료·단일 가격만 Offer에 쓰며, 티켓 재고·후기·별점·미확인 운영 조건은 생성하지 않는다. 질문과 답은 본문으로 제공하고 별도 FAQ 리치결과를 약속하지 않는다.
- 분야별·무료·저렴·마감 목록의 첫 HTML에 실제 행사 링크를 제공한다. 상세 정보를 브라우저에 모두 전달하지 않고 목록에 필요한 필드만 전달한다.
- 현재 목록에서 종료된 일정을 제외한다. 기존 상세 주소는 보존하며 종료 상세는 noindex·현재 행사 연결로 안내한다.
- 존재하지 않는 행사 ID는 React 응답이 시작되기 전에 HTTP 404와 noindex를 반환한다. 현재·보관·수동 등록 행사 ID를 모두 포함하는 작은 색인을 빌드 때 생성해 기존 URL을 보존한다.
- 확인된 내용이 실제로 바뀐 경우에만 행사 사이트맵 `lastModified`를 반영한다. 광고 영역은 검색 결과 설명에서 제외하도록 표시한다.
