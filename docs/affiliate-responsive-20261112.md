# 재료 체크·토스 광고·겨울 숙박 전환 개선

## 변경 내용

- 준비가이드 44개의 재료명과 원본 제휴 링크 430개를 보존한다. 기존 `prep-checklist:<slug>` 저장 키로 집에 있는 재료 체크를 복구하고, 체크한 항목에서는 구매 링크를 숨긴다. `없는 것만 보기`, 수량 표시, 초기화를 제공하며 구매 문구는 `구매하러가기`로 통일한다.
- 토스 메인 5개 고정 상품과 원본 추적 링크를 유지한다. 검토된 음식 사진을 원래의 3:1 비율로 크게 보여주고 어두운 덮개·중복 상품 썸네일을 제거한다. 가격·할인율·짧은 구매 버튼을 사진 아래에 배치한다. 실제 상품 조리 사진과 AI 연출을 구분한다.
- 하루특가는 6개에서 4개씩 표시해 사진을 키우고, 좁은 컨테이너에서는 2열로 배치한다. 중복 옵션·보관 설명을 줄이고 실제 종료 시각이 있는 상품에 `마감 전 구매하기`를 사용한다. 기존 품절·만료·피드 신선도 검사를 유지한다.
- 겨울여행 60개 글에 코스별 관람·식사·이동 계획을 추가한다. 당일치기에는 준비·귀가 계획을, 1박 코스에는 첫날 마지막 장소와 둘째 날 첫 장소를 기준으로 숙소 선택 및 총액·취소 조건을 비교하는 내용을 보강한다. 기존 제목·URL·본문·장소·사진·공식 출처를 보존한다. 운영시간과 요금을 새로 단정하지 않는다.
- 세시간전의 여기어때 프로그램에서 등록된 숙박시설 30개를 검색하고, 코스별 라벨을 붙여 원본 제휴 링크를 발급했다. 30개 링크를 계정의 등록 목록에서 다시 읽어 대조했다. `data/winter-stay-affiliates.json`은 발급 주소와 원본 숙소 주소를 보관한다. 개별 숙소 예약 연결은 첫날 일정이 끝난 자리에 표시한다.
- 호텔 객실·가격·재고를 제공하는 공개 API 명세는 이번 작업에서 확인하지 못했다. 새 숙박 가격 API를 연결했다고 보고하지 않는다. 숙박시설 등록·제휴 링크 발급 확인과 객실·숙박료 확인을 구분한다. 객실 요금과 옵션은 방문자가 날짜·인원을 선택한 예약 화면에서 확인한다.

## 반응형과 실행 비용

기기 이름 대신 뷰포트와 컨테이너 너비에 맞춰 사진·가격·버튼을 배치한다. 태블릿·펼친 폴더블에서도 메뉴가 과밀하지 않도록 전체 메뉴 전환점을 조정했다. 좁은 외부 화면, 가로 모드와 분할 화면을 고려하고, 안전 영역·키보드 포커스·44px 조작 영역·동작 줄이기를 유지한다. 컨테이너 쿼리를 지원하지 않는 모바일 브라우저에도 미디어 쿼리 대체 규칙을 제공한다.

실기기 Fold8·울트라폴드의 물리 기기를 시험한 결과가 아니다. 삼성의 [폴더블 레이아웃 지침](https://developer.samsung.com/one-ui/largescreen-and-foldable/designing_for_foldable.html)을 참고해 크기 변경과 상태 유지를 검증한다. 방문자 렌더링에 상품 API나 AI 생성 호출을 추가하지 않는다. 겨울 본문은 정적 콘텐츠이며 기존 NAS·캐시·토스 공용 피드를 사용한다. 전력량·전기요금·수익 증가를 측정한 결과는 아니다.

## 검증과 범위

- 회귀 검사 49개 통과: 상품 고정·만료·할인율·AI 고지·제휴 이벤트·기존 준비물 링크·겨울 공개 조건.
- 초기 운영 빌드 성공. 마지막 운영 빌드는 로컬 서버의 Windows 파일 잠금으로 한 번 실패해 시험 서버 종료와 작업본 `.next` 캐시 정리 후 재실행한다.
- 초기 로컬 HTTP 검사: 준비가이드 44개, 원본 제휴 링크 430개, 이미지 83개, Article/Breadcrumb와 기존 사이트맵 보존 통과.
- 초기 로컬 겨울 HTTP 검사: 60개 글 보존, 최소 784자 이상의 단락 보강, 30개 1박 코스의 예약 위치와 SEO 보존 통과. 숙박시설별 주소를 최종 연결한 빌드에서 다시 검사한다.
- 홈의 280·320·344·360·390·412·600·690·768·840·960·1024·1280·1440·1920px에서 가로 넘침 0, 음식 사진 비율 3:1을 확인했다. 체크 2개 → 구매 버튼 8개에서 6개, 없는 것만 표시, 344→840px 전환과 새로고침 후 체크 유지도 확인했다.
- 계정에 발급한 30개 숙박 링크와 라벨을 세 페이지에 걸쳐 다시 읽어 30개 모두 일치함을 확인했다. 제휴 단축 링크를 QA 목적으로 일괄 방문하지 않는다.
- 숙박 원본의 서버 HTTP 조회는 Cloudflare 403으로 제한됐다. 이를 객실·예약·숙박료 확인으로 해석하지 않는다. 세시간전의 등록 검색과 링크 발급·계정 목록 대조가 확인 범위다.

배포 커밋·NAS 실행 결과·최종 공개 검사 결과는 확인 후 별도 추가한다. 클릭은 예약·확정 수수료·정산과 구분한다.

### 최종 로컬 검사

운영 빌드가 정상 완료됐으며 1,412개 정적 페이지를 생성했다. 준비가이드 44개·제휴 목적지 430개·이미지 83개 및 겨울여행 60개·개별 숙소 링크 30개의 최종 HTTP 검사가 통과했다. 최종 겨울여행의 단락 분량은 1,350~3,226자이고 기존 대비 최소 784자 이상 늘었다. 본문에서 원래 제목·단락·장소 설명·기존 공식 링크·canonical·Article·사이트맵 보존을 확인했다.

최종 브라우저 검사는 홈 15개 너비, 준비가이드 목록·상세·겨울여행 목록·상세 각각 9개 너비, 가로·분할 화면 4개 조합으로 총 55개다. 가로 넘침은 없었다. 숙소 버튼은 48px 높이를 유지했다. 844×390px 가로 화면에서 전체 메뉴는 273px 높이로 화면 안에 놓이고 내부 스크롤이 가능했다. 하루특가는 4개씩 다음 상품 4개로 전환되며 기존 8개 상품을 확인했다. 실제 폴더블 하드웨어 시험 결과로 확대하지 않는다.
