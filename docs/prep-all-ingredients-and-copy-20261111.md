# 준비 가이드 전체 상품 연결 및 한국어 교정

사용자 요청: 꽃게탕 한 글에 한정하지 않고 대파 등 모든 재료와 조리도구를 연결하며, 준비 가이드와 사이트의 어색한 한국어 표현을 수정한다.

## 반영 범위

- 기존 준비 가이드 44개 URL과 발행 상태, 제목, 원본 제휴 URL을 유지했다.
- 기존 목록의 미연결 항목 262곳을 모두 보완했다. 요리 글 9개에는 원래 본문을 유지하면서 재료·양념·조리도구 목록을 추가했다.
- 캠핑용품·야외 놀이 글 2개에는 기존에 등록된 상품 4개의 원본 링크를 복원했다. 고리던지기 상품의 최소 연령 14세 안내를 유지했다.
- 최종적으로 44개 글의 표시 항목 430개 모두에 검토된 링크가 있다. 대파는 31곳, 양파는 30곳이며 같은 재료는 해당 상품 정보를 공유한다. 이는 서로 다른 상품 430종이라는 뜻이 아니다.
- AI 장면의 물체와 실제 상품이 완전히 같다고 주장하지 않는다. 판매처의 실제 상품 사진, 상품명과 포장 구성을 구분해 표시한다. 새 대표 이미지나 새 글을 발행하지 않았다.

## 상품 확인

`coupangFetch`와 기존 GitHub 공용 CAS 제한기를 사용했다. 검색은 limit=1, 다음 검색 전 7.1초 추가 대기, 실패 시 중단했다. 첫 조회 79회·추가 19회·최종 8회, 합계 실제 상품 API 106회와 캐시 1회를 순차 처리했다. 각 상품의 API 응답 시각을 후보 기록에 보존했다. 공유 기록의 더 엄격한 제한·영구 lock 규칙은 변경하지 않았다. 이 프로젝트 밖의 우회 호출까지 통제한다고 주장하지 않는다.

상품명 검색만으로 승인하지 않았다. 원본 사진과 옵션을 대조해 국자받침, 건조 버섯 선물세트, 양념깻잎, 깻잎순, 다른 맛이 섞인 볶음밥 등 맞지 않는 후보를 제외했다. 기존 등록 상품을 재사용한 경우 원래 확인 시각과 출처를 유지하고 이번 사진 검토 시각을 별도로 기록했다. 실제 재고·가격·배송 조건을 새로 보증한 것이 아니다.

상품 사진은 상품 번호별로 캐시를 분리하고 320px 이하 WebP로 저장했다. 연결에 사용하지 않는 이번 작업의 상품 사진 10개를 배포 파일에서 제외했다. 작업을 위한 일회성 GitHub Actions 정의는 수집 완료 후 제거했다. 정기 상품 수집이나 자동 발행은 추가하지 않았다.

## 한국어 교정과 검색 정보

- “이 활동에 어울리는 준비물” → 요리 글은 “필요한 재료와 조리도구”, 일반 용품 글은 “본문에서 소개한 상품”.
- “직접 준비할 재료”라는 표시로 상품 연결이 없는 상태를 정상 구매 동선처럼 보여 주던 문제를 해소했다.
- “국물육수 다시팩” → “육수용 다시팩”, “부대찌개 구성” → “부대찌개 밀키트” 등 항목 이름을 자연스럽게 정리했다. 판매처의 실제 상품명은 변경하지 않았다.
- “달걀와”, “버섯와”, “완성 요리 장면” 등 검색 설명과 사진 설명을 교정했다. 변경한 원문·수정문·위치는 `data/prep-copy-edits-20261111.json`에 기록했다.
- 준비 가이드 목록과 안내, 주말 추천·검색·캠핑장 모음·제휴 배너의 공통 문구를 다듬었다. 코드를 설명하던 문구는 독자가 장소와 상품을 고르는 데 필요한 안내로 바꿨다.
- Article의 about 정보를 실제로 표시하는 재료 목록과 일치시켰다. 기존 canonical과 사이트맵 URL은 유지했다. 확인되지 않은 가격·재고·별점·개인 경험을 추가하지 않았다.

## 검증

`node --test scripts/prep/affiliate-publisher.test.mjs scripts/prep/ingredient-completion.test.mjs scripts/prep/complete-guide-links.test.mjs scripts/affiliate-events.test.mjs scripts/prep/content.test.mjs`

21개 검사 통과: 기존 글·URL·원본 링크 보존, 기록된 교정만 허용, 44개 글 전체 연결, 대파·양파 전체 연결, 원래 요리 본문 유지, 연령 안내, API 중단·속도·단일 상품 규칙, 클릭 수집과 보고서 계약을 검사한다.

`node scripts/prep/verify-affiliate-render.mjs BASE_URL`

실제 HTML의 44개 글과 430개 항목 링크, 상품 사진 응답, canonical·Article·Breadcrumb·검색 허용, 사이트맵 44개 URL과 어색한 문구 제거를 확인한다. 제휴 목적지는 따라가지 않으며 쿠팡 상품 API도 호출하지 않는다.

클릭 수집은 기존 최소 정보 수집기를 이용한다. 클릭·노출 이벤트는 실제 구매·확정 수수료나 고유 방문자 전환율이 아니다. 검색 노출이나 매출 증가를 검증한 결과로 보고하지 않는다.
