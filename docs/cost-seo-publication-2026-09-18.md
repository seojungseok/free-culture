# 비용·준비물 SEO·자동 여행코스 점검

## 적용 범위

- `/weekend-prep`와 `/search`의 기본 화면은 정적 HTML/캐시로 제공한다. 검색·분류·페이지 매개변수가 있는 요청만 내부 결과 경로로 rewrite한다. 외부 주소와 서버 렌더링 결과는 유지한다. 빈 검색어는 기본 화면과 같은 canonical을 사용한다.
- 준비물 목록에 공개 24개 글의 주제별 HTML 링크와 CollectionPage/ItemList를 제공한다. 상세에는 원본 제목·본문·이미지·주소·제휴 링크를 유지하며 OG/Twitter, Article/Breadcrumb와 관련 글 연결을 보완한다. 내부 검색 결과는 noindex이고 사이트맵에 넣지 않는다.
- Google/Yeti/Bing/공유 봇 규칙, 상세 ISR 주기, 이미지 캐시 정책은 이번 작업에서 변경하지 않는다. 검색 순위와 월 요금 절감액은 보장하지 않는다. 배포 후 같은 길이의 12~24시간 사용량을 비교해야 한다.

## 실제 자동 발행 점검

9월 17일 일일 작업 `35158655951`, 통합 커밋 `06e593c`의 공개 데이터 전후 비교: 관광지 8, 여행코스 0, 시티투어 4, 입장권 0, 준비물 0. 신규 합계 12개. 기존 글 수정과 신규 발행은 구분했다. 준비물 보고서는 예약 초안 5슬롯 부족을 기록했다.

입장권 편집기 작업 `35156424855`, `35137419399`는 GitHub 진단에 `The hosted runner lost communication with the server`를 남기고 실패했다. 원인이 CPU/메모리인지 네트워크인지까지는 확인되지 않았다. 이번 변경으로 이 외부 실행기 문제가 해결됐다고 판단하지 않는다.

기존 일일 일정은 KST 05:00이다. GitHub schedule은 정시 실행을 보장하지 않으며 9월 17일 실제 작업 시작은 KST 07:38, 종료는 08:45였다. 일일 workflow에는 API 호출 없는 전후 공개 ID 비교와 수량 부족 경고를 추가했다. 이 보고서는 저장된 공개 데이터 기준이며 운영 배포 성공과 별도다.

## 여행코스 예약 작성 수정

- 기존 당일/1박2일/2박3일, 하루 목표 5/3/2, 관광지 상한 3/6/7과 하루 최대 3곳은 유지한다.
- 우선 예약 후보가 기간별 정원에 중복 가산되던 문제를 수정했다. 실패한 후보가 발행 여유를 차감하지 않는다.
- 후보는 최대 목표의 2배를 준비하고, 통과한 기간별 수량에 맞춰 다음 후보를 선택한다. 본문 신규 작성 시도는 하루 최대 목표(기본 10건), 건당 기존 2회 한도다. 기존 글 보완 시도는 COURSE_REBUILD_MAX 이내다. 구성 검사는 신규 목표의 2배 + 보완 상한 이내다.
- `_generationHistory`에 재료 fingerprint와 보류 이유를 저장한다. 일반 반려는 3일, 일시 실패·본문 반려는 1일 후 재검토한다. 코스 재료가 달라지면 먼저 검토할 수 있다. `_generationBudget`은 한국 날짜 기준이며 같은 날 재실행에 재사용한다.
- 구성 검증에는 실제 노출할 경유지의 일차별 배분·주소·좌표·근거를 전달한다. 미확인 운영·배편을 추정하지 않으며 검증 응답 오류는 승인으로 처리하지 않는다. 본문 품질·경유지 일치·사실 검사와 총발행 상한은 그대로다.
- `COURSE_CHECK_ONLY=true node scripts/generateCourses.mjs`는 API/파일 저장 없이 다음 후보를 점검한다. 이번 실데이터 점검에서는 지난 실패 10건을 보류하고 세 기간의 대체 후보를 확인했다. 실제 유료 자동 생성의 성공은 다음 실행 결과로 확인해야 한다.

## 검증

로컬 빌드 1,070페이지, TypeScript, 사이트맵/SEO, 준비물 24개·72이미지 참조·제휴 링크, 정적 기본 화면/동적 검색 rewrite, 390/1280px 브라우저 검색·분류·페이지 이동·뒤로가기를 확인했다.

유료 모델을 가짜 응답으로 대체한 격리 테스트에서 구성 반려 후 대체 후보로 5/3/2 발행, 같은 날 재실행 시 추가 작성 없음, 오류 시 발행 거절을 확인했다. 테스트 초안은 `.cache`에만 생성하며 공개 데이터에 넣지 않는다.
