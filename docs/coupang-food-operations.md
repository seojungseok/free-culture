# 주말에 뭐하지 쿠팡 먹거리 운영

2026-10-30 사용자 지시에 따라 이 사이트의 상품 검색과 단일 상품 링크 발급은 `scripts/prep/coupang.mjs`의 `coupangFetch`를 거친다. 검색은 `limit=1`, 링크 발급은 상품 URL 1개만 허용하며 두 호출 모두 요청 1회·상품 1개로 차감한다. GitHub 공용 기록의 CAS·잠금·6.1초 이상 간격·직전 60초 최대 10회와 10개, 더 엄격한 기록 상한, 실패 차감, 429 대기를 지킨다. 불명확한 잠금은 자동으로 제거하지 않는다.

이 제한은 이 사이트에서 통제하는 호출을 대상으로 한다. 같은 계정의 다른 프로그램이 공용 기록을 사용하지 않으면 계정 전체 합계는 보장되지 않는다. 사용자는 다른 프로그램을 확인하거나 변경하지 말라고 요청했다.

GitHub Actions가 매일 00:12 KST에 상품을 갱신하도록 예약되어 있다. 실행은 GitHub 상황에 따라 지연될 수 있다. 액세스 키와 시크릿은 기존 GitHub Actions 비밀 설정을 사용하며, 기록 접근에는 해당 실행의 단기 GitHub 토큰을 사용한다. 확인된 응답의 상품·옵션·제휴 계정·`mwohaji` 채널을 대조하고 API 제공 사진을 압축한 후에만 데이터와 사진을 함께 커밋한다. 오류 시 기존 데이터가 유지된다. NAS는 기존 매시간 동기화로 변경을 배포한다.

방문자는 저장된 상품·이미지만 읽으며, 방문이나 광고 노출로 쿠팡 상품 API가 호출되지 않는다. 상품 데이터가 7일 이상 갱신되지 않으면 광고를 숨긴다. 가격·할인·이벤트 및 판매량은 확인되지 않으면 표시하지 않는다. 광고 배경은 AI 연출이고 상품 이미지는 API 제공 원본을 압축한 것이다.
