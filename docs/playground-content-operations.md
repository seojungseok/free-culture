# 어린이 놀이터·물놀이터 운영

2026-11-16 신규 연결. 기존 글과 URL, 제휴 정보는 그대로 유지한다.

## 수집과 공개 범위

- 행정안전부 전국어린이놀이시설정보서비스(15124519), `pfc3/getPfctInfo3`의 도시공원 A003·하천 A031·공공도서관 A033 전체 페이지를 수집한다.
- API 활용승인 후 실제 28회 요청으로 12,657건을 확인했다. 공개 목록은 공공 소유·운영 상태·지역 확인 시설 12,229건이며, 동일 공원에 여러 등록시설이 있을 수 있다. 장소 수나 현장 개방 수가 아니다.
- 학교·어린이집·유치원·주택단지·민간시설·이용금지 시설은 공개 검색에서 제외한다. 공공시설이라는 사실만으로 일반인 상시 입장·무료 이용을 보장하지 않는다.
- 주소가 불완전하면 API 행정구역명과 제공 주소를 함께 표시한다. 좌표는 국내 범위를 확인한다. 물놀이기구 X001은 포함, X002는 미포함이며 시즌 개장 여부를 의미하지 않는다.
- 인증키는 기존 `DATA_GO_KR_KEY` 환경변수/저장소 Secret에서만 읽는다. 오류 본문·키·요청 URL은 출력하지 않는다.

## 자동 갱신

- 기존 daily GitHub Actions(매일 05:17 KST)에 `collectPlaygrounds.mjs`를 연결했다. 500건씩 순차 수집, 요청 시작 사이 최소 700ms, 최대 160회이며 방문자 렌더링은 API를 호출하지 않는다.
- 모든 분류·페이지의 건수·중복·페이지 번호·전체 건수 일치를 검사한다. 부분 실패·인증 실패·빈 전체 응답·시설 수 20% 이상 급감 시 기존 파일과 확인시각을 유지한다.
- 목록에서 사라진 항목은 active/listed=false로 보관한다. 기존 상세글 URL은 삭제하지 않고 운영 미확인 안내 및 noindex로 전환한다.
- `data-status`에 놀이시설 최신성(36시간)도 포함한다. 수집이 멈췄을 때 조회시각을 현재 시각으로 바꾸지 않는다.
- 공원 관광정보는 화요일에 기존 TourAPI 공통 클라이언트로 20곳의 공통·소개·반복정보를 재조회한다(기본 60회, 재시도 포함 최대 72회). 화요일 총예산에도 반영하며 월요일의 기존 1,000회 예산에는 추가하지 않는다. 제공기관 한도 도달 시 75로 연기한다.
- 시간·주차·휴무·문의가 편집 검토 당시와 달라지면 `introChangedSinceReview=true`로 기록하고 상세페이지에 재확인 안내를 표시한다. 편집 본문과 검토한 사진은 자동으로 재작성하지 않는다.

- 첫 발행 5편: 서울어린이대공원, 인천 늘솔길공원, 부산시민공원, 울산 대왕암공원 미르놀이터, 제주 삼무공원. 관광 API 확인 2026-11-16, 원자료 변경일·현장 점검일과 구분한다.

- 늘솔길 양떼목장 관람시간은 관광 API의 공원/목장 개별자료 및 인천투어 간 불일치를 그대로 알린다. 임의로 한쪽을 확정하지 않는다.
- 이용 후기·별점·권장 연령·미확인 요금·미확인 운영시즌을 만들지 않는다. 물놀이터의 다음 해 운영일을 지난 일정으로 채우지 않는다.
- 수정 시 장소별 출처를 다시 확인하고 실제 내용이 바뀔 때만 편집 날짜·Article/sitemap lastmod를 갱신한다. API를 조회했다는 이유로 글의 작성일을 매일 바꾸지 않는다.

## 11월 16일 계절·운영 검증 반영

- 겨울(11~3월)은 공식 운영안내·공지를 대조한 실내시설만 메인에 우선 노출한다. 기준일은 2026-11-16이며 이번 주말은 11-21~22다. 야외 5편에 더해 대전 나무상상놀이터·전북어린이창의체험관·김해 꿈크는나무놀이터·춘천 꿈자람 실내공원 4편을 작성했다. 총 9편·실제 API 사진 18장이다.
- 춘천의 11-11은 공지 등록일이며 실제 임시휴장은 **2026-11-24 하루**, 11-25부터 정상 운영이다. 게시글 본문 이미지를 직접 확인했다. 등록일을 휴장 시작일로 사용하지 않는다. 종료된 점검 공지는 현재 휴장으로 처리하지 않는다.
- `data/playground-operations.json`에 공식 안내·공지 검토 기준, 정기휴관, 날짜별 예외를 저장한다. 매일 공식 HTML을 확인해 검토 본문과 달라지거나 조회가 실패하면 review-required로 바꾸고 추천에서 보류한다. 72시간 이상 재확인되지 않은 시설도 메인에서 제외한다. 자동으로 변경된 내용을 승인하지 않으며, 실제 내용을 검토한 뒤에만 기준을 갱신한다.
- 기본 목록은 사진·요금·운영시간·예약 정보를 갖춘 9개 방문 안내글이다. 실내·무료·야외 및 지역 필터가 이 글 목록에 적용된다. 주소 중심의 원자료는 별도 접기 영역에서 선택해 조회한다. 물놀이를 추천하려면 해당 방문일이 확인된 개장기간 안에 있어야 한다.

- 전체 관광정보는 9곳이며 문화시설 유형 14도 해당 유형으로 조회한다. 운영기관의 놀이터 회차와 관광 API의 건물 개방시간을 구분한다. 실시간 예약 잔여석이나 지금 입장 가능 상태를 추정하지 않는다.

## 11월 17일 지역·요금·본문 개선과 문체 기준

- 메인은 상단 체험·교육과 같은 `ExperienceBrowser` 카드·그리드·제목·지역 바로가기 스타일을 사용한다. 사용자 요청으로 설명 문구, 기준 주말과 예약처 확인 문장은 삭제했다. 같은 의미의 대체 문구도 덧붙이지 않는다.
- 관광 API `detailCommon2`·`detailInfo2`를 추가 조회해 9곳의 도로명주소·공식 사이트·좌표·입장료·주차요금·화장실 등 19개 상세 항목을 보강했다. 시설 등록주소와 실제 안내주소가 다르면 장소 운영기관의 방문주소를 우선한다.
- 무료 필터는 입장료가 무료인 5곳만 포함한다. 보호자·영아·주차만 무료인 유료시설을 전체 무료로 분류하지 않는다. 실내시설의 보호자·영아·다자녀 무료 조건과 필요 증빙은 본문과 방문 요약에서 설명한다.
- 안내글 상단에 주소·이용요금·무료 조건·시간·예약·대상·주차·휴관·연락처를 배치한다. 원자료·출처는 필요할 때 여는 영역으로 제공하며 기존 글 URL과 사진 원본·이용조건은 보존한다.
- 놀이시설 글 9편의 37개 섹션을 설명체로 검토했다. 문장 종결은 `~입니다 / ~합니다`를 기본으로 한다. 제목은 `운영시간과 예약 방법`, `이용요금과 무료 대상`처럼 내용이 드러나는 명사형으로 작성한다.
- `먼저 정해요`, `골라보세요`, `참고해보세요` 같은 권유형 제목·문장과 불필요한 부모 훈수, 작성 과정·검색 과정 설명을 넣지 않는다. 요금·시간·예약·놀이 내용은 구체적으로 설명하고 반복되는 주의문으로 분량을 늘리지 않는다.
- 목록 아래의 공통 질문·답변, `놀이터 나들이, 주소 다음에 확인할 정보` 등 사용자 삭제 요청 블록은 재생성하지 않는다. 이용조건을 바꾸는 실제 제한과 날짜별 휴장은 해당 장소에만 표시한다.

## 11월 17일 지역별 방문 안내 확장

- 기존 9편의 URL을 유지하고 11편을 추가해 총 20편으로 확장했다. 17개 시도에 각각 안내글이 있으며 실내 11편, 일반 입장·관람 무료 15편이다. 무료 시설도 별도 교육·체험·주차 조건을 본문에서 구분한다.
- 추가 장소는 안산갈대습지 생태누리관, 삼척 그림책나라, 영동 과일나라테마공원, 광주 빛고을농촌테마공원, 구미 새마을운동테마공원, 동두천 놀자숲, 김해 화포천습지과학관, 대구 두류공원, 아산 신정호공원, 순천 조례호수공원, 세종호수공원이다. 공식 확인이 어려웠던 후보는 발행하지 않았다.
- 실제 관광 API 사진 22장을 추가해 총 40장이다. 공공누리 제3유형은 원본 바이트·SHA-256을 보존한다. 전시관·도서관·공원 전경 사진을 실제 놀이터 내부 사진으로 설명하지 않는다.
- 구미와 화포천의 현재 운영·예약 안내 및 최신 공지를 대조하고 메인 추천 검토에 추가했다. 겨울 메인은 운영 확인된 실내시설 중 무료 시설을 우선하며 지역 바로가기는 17개 시도 전체를 연결한다. 야외시설은 분야·지역 목록에서 이용한다.
- 새 글에는 개별 최초 발행일을 저장하고 기존 9편의 최초 발행일은 유지한다. Article·OG·사이트맵은 실제 발행·수정일을 사용한다.
- 20곳의 주간 관광 API 재확인은 기본·운영·상세 각 1회로 60회이며 재시도를 포함해 72회에서 중단한다. 화요일 일일 요청 예산은 총 482회이며 월요일 1,000회 상한은 유지한다. 호출 실패·예산 초과 시 불완전 결과로 기존 파일을 교체하지 않는다.
