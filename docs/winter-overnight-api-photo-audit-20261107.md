# 겨울 1박 2일 장소·사진 수집 확인

확인일: 2026-11-07 KST. 이 보고서는 수집 자료와 로컬 사진 검토 결과이며 배포·검색 노출 성과를 뜻하지 않는다.

## 실제 확인 결과

- 신규 20코스, 검색 권역 17지역, 장소 86곳. 장소의 TourAPI ID·제목·원문 주소·좌표를 계획과 대조하고 모든 `plans[].stops[].matchReviewed`를 승인했다.
- TourAPI 실제 시도 136회: `searchKeyword2` 106회, `detailImage2` 30회. `scripts/lib/tourClient.mjs`를 사용했고 이 작업 전체 상한은 재시도 포함 200회였다. 제공기관 한도 오류 시 공통 수집기가 중단한다.
- 네이버 공개 검색 20건 모두 HTTP 200. 기존 환경에 네이버 검색 API 인증은 없어 공개 검색 페이지를 사용했다. 검색 결과는 장소 발견용이며 운영시간·휴관·요금의 사실 근거로 삼지 않는다.
- 로컬 WebP 70장, 서로 다른 파일과 SHA-256 해시 70개, 총 7,581,806바이트. 가로 1,200·세로 900픽셀 안에 비율을 유지해 저장했다. 모든 코스에 사진 3~5장이 있다.
- 선택 사진 전부 원본 응답에서 `cpyrhtDivCd=Type1`을 확인했다. Type3 자료는 새 변환 사진으로 사용하지 않았다. API 사진 URL, 장소 ID, 출처·이용조건, 확인시각을 보존했다.
- 4개 접촉표의 70장을 실제 확인했고, 전등사 교체 사진 2장은 원본 크기로 추가 확인했다. 사진마다 `reviewed=true`, `reviewedAt`이 있다.
- API 응답에서 장소를 확인한 시각은 2026-11-06 15:30:26~15:36:03 UTC이며, 한국 시각으로 11월 7일 00:30~00:36이다. 제공기관의 장소 수정일 범위는 2025-07-18~2026-11-04다. 이번 조회 시각을 모든 시설·사진의 제작일이나 최신 촬영일로 표현하지 않는다.

## 매칭에서 바로잡은 내용

- `전주한옥마을` 검색에 포함된 숙박업소를 제외하고 실제 관광지 264284를 선택했다. 같은 이름의 숙박업소 `경기전 연가`도 제외했다.
- `증심사 계곡 안산암질용암` 대신 사찰 `증심사(광주)` 126351을 선택했다.
- `문의문화재단지`는 현재 원문 명칭 `문의문화유산단지` 127032에 연결했다. 검색용 query와 원문 명칭을 구분했다.
- 여주한글시장은 네 가지 검색어로도 확정할 TourAPI 레코드를 찾지 못했다. ID를 만들지 않고, 담당 작성자·조립 담당과 합의하여 여주 코스를 신륵사·여주박물관 / 목아박물관·명성황후 생가의 4곳으로 조정했다.
- 안동시립박물관 휴관을 확인한 작성자의 요청에 따라 유교문화박물관 130673을 사용했다. 사진의 입구 표지에서 유교문화박물관 본관임을 확인했다. 별도의 세계기록유산 전시체험관과 혼동하지 않았다.
- 원문 주소는 현재 API 응답 그대로 보존한다. 지역 필터의 `광주`·`전남`은 여행 검색 권역이며 주소 문자열을 이전 행정명으로 변환하지 않는다.

## 사진 검토와 표현

- 접촉표: `.cache/winter-overnight-review/sheet-0.jpg`~`sheet-3.jpg`; 번호·장소명 대응은 같은 폴더 `index.json`.
- 전등사는 캐시의 Type1 원본 `눈 내린 전등사`, `강화 전등사_산사의 설야 (공모전)`를 선택했다. 설경과 야간 건물 사진은 서로 다른 구도다. 눈 상태를 방문일에 보장하지 않는다.
- 강화·광주·여수는 같은 장소의 서로 다른 실제 장면을 `place.gallery`에 추가했다. 광주는 미술관 외부와 내부, 여수는 향일암 건물·바다 전망·다른 건물 풍경으로 구분된다.
- 전주 한옥마을 API 대표 사진은 전동성당을 담고 있어, alt와 caption을 `전주 한옥마을 일대 전동성당`으로 명시했다.
- 일반 계절 사진에는 겨울·설경이라는 표현을 붙이지 않고 자료 사진으로 표시한다. 눈 사진도 당일 촬영이나 현재 적설량으로 표시하지 않는다.
- 모든 로컬 파일은 `public/winter-photos/overnight-*.webp`에만 추가했다. 기존 당일치기 자료와 기존 사진을 교체하는 스크립트는 실행하지 않았다.

## 재현 파일과 자료 계약

- 수집기: `scripts/prepare-winter-overnight-places.mjs`
- 장소·권리·선택 사진: `data/winter-overnight-places.json`
- 네이버 탐색: `data/winter-overnight-naver-research.json`
- 원고 조립: `plans[].stops[].query/day/id`와 `places[id]`를 연결한다. 각 장소의 `photo` 및 선택적인 `gallery`는 같은 장소 ID를 가진다. 사진이 없는 장소에 임의의 다른 장소 사진을 배정하지 않는다.
- 비밀키는 기존 환경 파일에서 읽으며 데이터·로그에 저장하지 않았다. 신규 데이터에서 키 쿼리와 인증값 노출 패턴이 없는지 확인했다. 쿠팡 API, 제휴 추적 POST, 비공개 운영 로그는 접근하지 않았다.

## 적용 원칙과 검사 범위

Agency Agents의 `testing-api-tester`와 `testing-reality-checker` 역할에서 계약·예산·오류 처리·실제 증거 확인 원칙을 적용했다. 이번 작업은 허가된 자료 수집과 로컬 검토이며, 외부 API 부하·침투 테스트는 하지 않았다. 게시된 페이지의 반응형 UI·SEO·배포 응답은 최종 조립 담당의 별도 검사 대상이다. 운영시간·입장료·휴관일은 두 원고 작성자의 공식 기관 자료 검증을 따른다.
