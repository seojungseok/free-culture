# 홈 디자인 점검 — 2026-11-06

## 기준과 범위

'주말에 뭐하지?'의 기존 네이비 로고, 파랑 탐색 기능, 지역별 나들이 정보 구조를 유지했다. 새 장식 문구나 사진을 추가하지 않고 검색 → 지역 선택 → 카드 → 상세 글의 순서를 정리했다.

Agency의 UI Designer, Brand Guardian, UX Architect 원문 지침을 읽고 적용했다. 이 3종을 추가해 설치된 역할 지침은 총 12종이다. 기존 사이트의 보완이므로 새 사이트용 테마 전환 기능이나 별도 디자인 시스템 제품은 추가하지 않았다.

## 구현 내용

| 영역 | 확인한 문제 | 반영한 수정 |
| --- | --- | --- |
| 첫 화면 | H1이 화면에서 숨겨져 검색창만 보임 | 기존 H1 '이번 주말, 어디 갈까요?'를 노출하고 검색 버튼을 네이비로 구분 |
| 카테고리 | 아이콘과 이름의 간격·시각적 무게가 분산됨 | 기존 이모지를 유지하며 같은 크기의 옅은 블루 배경과 간격 적용 |
| 빠른 이동 | 내 주변·이번 주말·맞춤 추천·보관함의 터치 높이가 일정하지 않음 | 4개 항목을 같은 행의 최소 44px 버튼으로 정리 |
| 지역 선택 | 모바일 가로 스크롤에서 일부 지역이 처음에 보이지 않음 | 나들이 9개 지역 버튼을 줄바꿈해 표시, 선택 상태를 네이비로 통일 |
| 일반 카드 | 가로 목록 우측 카드가 숨고 작은 메타정보 대비가 낮음 | 기존 최대 8개를 모바일 2열·태블릿 3열·PC 4열로 표시, 16:10 사진·16px 모서리·13px 진한 메타정보 적용 |
| 겨울여행 홈 영역 | 20편 모두를 한 열로 표시하면 홈이 지나치게 길어짐 | 전국 선택은 서로 다른 지역의 6편 요약, 특정 지역은 해당 글 모두 표시, '전국 20개 코스 보기'로 연결 |
| 겨울여행 목록 | 원래 요청의 20개 글 탐색이 필요함 | /winter-travel에서 20개 전체 카드와 지역 필터 유지 |
| 사진 대체텍스트 | 첫 경유지 이름을 대표사진 이름으로 가정해 대전 사진과 불일치 | 실제 검수한 대표사진의 alt 값을 홈에 전달 |
| 헤더 선택 표시 | PC 선택색이 초록이고 밑줄이 링크 바깥으로 내려가 가려질 수 있음 | 선택색을 파랑으로 통일하고 밑줄을 링크 안에 배치, 모바일 항목 최소 44px |
| 키보드·모션 | 공통 포커스와 모션 선호 대응이 부족함 | 공통 focus-visible 윤곽선, reduced-motion 사용 시 부드러운 문서 스크롤 해제 |
| 무료 필터 | 후보가 주말 행사인데 '무료 행사'로 표시됨 | 실제 범위에 맞게 '주말 무료 행사'로 표시 |

홈 겨울 대표 6편은 서울·강원·부산·경기·전남·제주에서 한 편씩 선택한다. 인기순·매출순이라는 의미는 없다. 원고 20편과 사진 60장, 기존 광고 순서·고정 토스 5상품·하루특가 피드·제휴 URL·계측 코드는 보존했다.

## 색과 글자

- 네이비 #102344: 제목, 검색 버튼, 선택한 지역.
- 파랑 #2563EB: 탐색 링크와 활성 메뉴.
- 보조 글자 #64748B: 기존 ink-faint를 더 진하게 조정.
- 초록 #15803D: 무료 상태와 기존 무료 기능. 탐색의 활성 상태는 파랑으로 구분.
- 홈 카드 메타정보에는 별도 진한 보조색 #526174를 사용한다.

sRGB 색상 성분을 선형화한 상대 휘도로 흰 배경 #FFFFFF와의 대비를 계산했다. 반투명 배경이나 사진 위 실제 합성색을 측정한 결과는 아니다.

| 토큰 | 색상 | 흰 배경 대비 |
| --- | --- | ---: |
| brandblue | #2563EB | 5.17:1 |
| ink-faint | #64748B | 4.76:1 |
| free | #15803D | 5.02:1 |

이 세 색상 쌍의 계산 결과를 사이트 전체 WCAG 준수 판정으로 확대하지 않는다. 이미지 위 배지·광고·기타 색상과 키보드/보조기기 사용성은 별도 검사가 필요하다.

## 검증 상태

- 디자인 구현 후 TypeScript 검사와 git diff --check 통과.
- 위 색상 3쌍의 흰 배경 대비를 스크립트로 재계산해 확인.
- 앞선 겨울여행 개편의 브라우저·HTTP 검증은 디자인 보완 전 판본에 대한 결과다.
- 디자인 보완을 포함한 최종 운영용 빌드가 통과했다(Next.js 15.5.21, 1,362개 정적 페이지). 320/390/1280px 실제 브라우저에서 문서 가로 넘침 0, 일반 카드 2/2/4열, 나들이 지역 버튼 9개를 확인했다.
- 390px에서 빠른 이동 4개 버튼 높이 각각 44px, 홈 겨울 전국 6개 → 경기 2개 → 제주 1개 필터를 확인했다. 전체 코스 링크 이동 후 20개 카드를 확인했다.
- PC 겨울 메뉴의 선택 파랑 rgb(37,99,235), 옅은 배경, 밑줄이 링크 영역 안에 있음을 확인했다. 공개 서버 반영 여부는 배포 후 별도 검사한다.
- 실제 사용자 Core Web Vitals, 체류 시간, 검색 노출, 제휴 매출 개선은 측정하지 않았다.

최종 실화면 확인 항목: 보이는 H1과 검색, 지역 9개 줄바꿈, 빠른 이동 4개 버튼, 일반 카드 2/4열, 홈 겨울 전국 6편→경기 2편→제주 1편, 전체 목록 20편 연결, 대표사진 대체텍스트, 숙소 배너 겹침, PC 활성 메뉴 밑줄.
