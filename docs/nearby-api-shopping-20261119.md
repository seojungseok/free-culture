# 내 주변 검색과 메인 상품 점검

2026년 11월 19~20일 한국시간 기준. 아래 결과는 같은 좌표와 직선거리 10km 조건에서 비교했다. 행사 종료와 수집 시점에 따라 건수가 달라진다.

평창의 첫 화면에는 맛집, 나들이, 놀이터, 카페 데이트 코스, 농촌 체험, 캠핑장, 반려동물 동반 장소가 나왔다. 전체 검색에서 각 종류의 가장 가까운 결과를 먼저 보여준다. 가까운 순 정렬, 종류 선택, 더보기를 지원한다. 좌표가 없는 강좌와 체험은 직접 선택한 시·도에서 찾을 수 있다. 다른 자료의 좌표를 사용할 때는 동일한 시설 주소가 한 좌표로 확인돼야 한다.

## 수집 결과

- 기존 공공 API 20개 경로에 소량 조회를 실행했다. 문화행사, 관광지, 음식점, 관광축제, 고캠핑, 반려동물 여행, 무장애 목록·상세, 관광사진, 놀이터, 청소년활동, 농촌체험마을, 평생학습강좌, 네 지역 축제와 주차장 세 경로다. 수집 파일 18종에서 각 자료의 예정 수집 주기를 확인했다. 부분 상세 수집 항목은 전체 시설의 개별 재확인 일자가 서로 다르다.
- 고캠핑 목록에서 3,126곳을 확인했다. 운영 3,015곳, 휴장 111곳이다. 주변 검색은 휴장과 현재 원본 목록에서 빠진 곳을 제외한다. [고캠핑 정보조회](https://www.data.go.kr/data/15101933/openapi.do)
- 무장애 여행 상세에서 성공 응답에 편의 항목이 없는 경우와 API 장애를 구분했다. 상세 24곳을 확인했고, 업데이트한 편의정보는 총 220곳이다. [무장애 여행 정보](https://www.data.go.kr/data/15101897/openapi.do)
- 주차장 위치·운영·실시간 조회는 공식 버전 1 경로 세 개의 응답을 각각 확인했다. 12개 지역에서 추린 주차장 694곳을 갱신했다. 운영정보가 연결된 곳은 120곳, 실시간 조회 식별자가 연결된 곳은 8곳이다. 실제 잔여 면수는 제공 기관의 응답 시각에 따라 달라진다. [주차정보 조회](https://www.data.go.kr/data/15099883/openapi.do)
- 부산·경주·울산·전남의 축제 기간에서 한글 요일, 생략된 연도와 종료일을 처리했다. 네 지역의 해당 피드에서 진행·예정으로 확인된 추가 행사는 0건이었다. 다른 출처를 포함한 축제 자료는 434건이다.
- 추가 후보로 공공개방 체육시설에서 위치·이용시간·이용요금을 함께 제공하는지 확인했다. 걷는 길과 강좌는 주소만으로 출발지나 수업 장소의 정확한 거리를 확정하기 어려운 항목이 있다. 이번 배포의 새 검색 결과는 운영 데이터에 있는 시설·일정으로 구성했다. [공공개방 체육시설](https://www.data.go.kr/data/15013117/standard.do) · [걷는 길](https://www.data.go.kr/data/15017321/standard.do) · [평생학습강좌](https://www.data.go.kr/data/15013110/standard.do)

## 메인 상품

운영 토스쇼핑 피드에서 원래 상품명, 옵션, 사진, 가격과 제휴 목적지를 확인했다. 추운 날 외출용 방한용품 두 가지와 따뜻하게 먹는 겨울 먹거리 세 가지를 선정했다. 판매량 순위 자료는 없었다.

| 상품 | 확인한 구성 | 사진 장면 |
| --- | --- | --- |
| 부산포차 꼬치어묵 | 400g × 3봉 | 김이 오르는 냄비에서 건져 든 꼬치 |
| 쟈니베어 특대형 핫팩 | 180g × 30개입 | 장갑 낀 손으로 주머니에 넣는 핫팩 |
| 기모 마스크 넥워머 | 다이아 패턴 2종 세트 | 브라운과 블랙 넥워머의 패턴과 안감 |
| 해남 베니하루카 꿀밤고구마 | 특상·세척 3kg 한 상자 | 껍질을 열어 노란 속을 드러낸 고구마 |
| 미미네 오리지널 국물떡볶이 | 570g × 4봉 | 숟가락으로 뜬 떡과 국물 |

토스 API에서 동일 핫팩의 옵션명이 ‘180g, 30개입, 1개’로 변경된 것을 확인해 수집 기준을 갱신했다. 원본 링크 5개를 모바일 브라우저 요청으로 열어 최종 토스쇼핑의 상품명·식별자와 HTTP 200 응답을 확인했다. 사진·문구·버튼 어디를 눌러도 같은 창에서 해당 상품으로 이동한다.

판매자 사진을 참고해 새로 만든 연출 사진에는 AI 연출 표시를 붙였다. 사진에 글자를 넣지 않고 화면 너비에 따라 제목과 가격을 표시한다. 노출과 상품 클릭은 상품 ID별로 집계하며 구매·수수료는 제휴사 실적으로 따로 확인해야 한다. 품절, 상품명 변경, 만료, 6시간 이상 지난 피드가 감지되면 해당 상품을 숨긴다.

로컬 운영 빌드에서 320, 390, 768, 1440px 폭으로 상품 5개를 전환해 제목·가격·사진·링크를 확인했다. 위치 허용과 거부, 수동 지역 선택, 종류·정렬 변경, 다음 12개 추가, 놀이터의 해당 등록시설 연결을 확인했다.
