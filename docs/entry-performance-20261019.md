# 첫 방문 성능과 지역 수집 부분 장애

- 실패 실행 39172092258(일일), 39165345702(주간)은 모두 경주 지역 축제 API의 temporary_network가 원인. 다른 수집 단계와 데이터 커밋은 완료됐다.
- 2026-10-19 직접 최소 요청에서도 약 30.6초 뒤 HTTP 200/resultCode 1 제공기관 오류를 확인했다. 제공기관 복구로 보고하지 않는다.
- 일부 지역의 통신 장애는 degraded로 저장하고 작업 경고와 요약에 실패 지역·최신성 미확인·기존 자료 보존을 명시한다. 마지막 정상 checkedAt을 갱신하지 않는다. 인증·형식 오류와 전체 지역 장기 장애는 실패를 유지한다. 매 실행 제한된 재시도를 유지한다.
- 신규 자동 글 발행은 기존 publication-policy.json과 일일 workflow에서 중지된 상태다. 사용자의 조건부 요청에 따라 새 예약을 켜지 않았다. 현재 하루 신규 자동 글 0개.
- 외부 Pretendard CSS의 render-blocking @import를 제거하고 비차단 스타일시트로 로드한다. 글꼴·본문 스타일과 JavaScript 비활성화 fallback을 유지한다.
- 홈에서 첫 화면 아래 section의 layout/paint는 content-visibility로 지연한다. 콘텐츠·순서·URL·제휴 링크·추적은 보존한다.
- 검증 결과와 운영 반영 상태는 검증 완료 후 추가한다.
