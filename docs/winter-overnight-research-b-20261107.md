- 범위: 광주 1, 전남 2, 대구 1, 경북 2, 부산 1, 울산 1, 경남 1, 제주 1편.

## 운영 공지로 변경하거나 주의한 사항

1. **안동시립박물관 제외:** 안동시의 [본관 임시 휴관 공고](https://www.andong.go.kr/portal/saeol/gosi/view.do?isLinkage=Y&mId=0401020100&notAncmtMgtNo=65021)는 리모델링에 따른 2026-10-19~2027-01-04 휴관을 안내한다. 이 시설을 제외하고 도산서원과 연결되는 한국국학진흥원 유교문화박물관 본관을 넣었다.
2. **유교문화박물관과 별도 전시체험관 구분:** [공식 홈페이지](https://koreastudy.or.kr/cfseum/)의 2026-11-22 휴관 공지와 세계기록유산 전시체험관 2026-11-03~12-31 임시 휴관을 확인했다. 원고는 본관을 대상으로 하며 별도 전시체험관 및 중단된 VR·AR 체험을 일정에 넣지 않았다. 월요일 및 특별 휴관일 확인을 안내한다.
3. **태화강전망대 카페를 휴식처로 지정하지 않음:** [태화강국가정원 공식 홈페이지](https://www.ulsan.go.kr/s/garden/main.ulsan)의 2026-07-23 카페 운영 종료 공지를 확인했다. 실내 휴식은 점심과 울산박물관에 배분했다.
4. **목포근대역사관은 1관만 사용:** 목포 관광 안내에 2관 임시 휴관 안내가 있어 [1관 안내](https://biz.mokpo.go.kr/tour/attraction/museum?idx=7449&mode=view)를 별도로 확인했다. 2관을 함께 개방한 장소로 소개하지 않았다.
5. **석굴암은 겨울 도로 통제 확인:** [석굴암 관람 안내](https://www.seokguram.org/bbs/content.php?co_id=price)의 폭설·기상특보에 따른 입장 제한 안내를 반영했다. 일출이나 일몰 시간 방문을 넣지 않고 낮에 관람하며 통제 시 일정을 조정하도록 했다.
6. **제주 개화·해안 통제 구분:** [카멜리아힐](https://www.camelliahill.co.kr/)과 [비짓제주 주상절리 안내](https://www.visitjeju.net/kr/detail/view?contentsid=CNTS_000000000020476&menuId=DOM_000001718001000000)를 참고했다. 특정 시기 동백 만개를 보장하지 않으며, 해안 통제 시 제주국제평화센터 실내 관람으로 시간을 조정한다.

## 검증 범위와 한계

직접 열람 가능한 공식 본문을 우선했다. 일부 사이트는 방화벽·자바스크립트·시간 초과로 본문 직접 열람이 제한되어 공식 검색 결과와 지자체 또는 한국관광공사 안내를 교차 확인했다. 이 기록은 모든 출처 URL에 대한 HTTP 상태 검사나 방문 당일 개방 보증이 아니다. 원고의 출처 확인일은 조사일이며 시설 운영 보증일이 아니다.

원고 10편의 고유 slug, 지역별 편수, 두 날짜별 2곳 이상, `overnightArea`, 소개 100자 이상, 장소 설명 100자 이상, 글마다 3개 섹션, 공식 HTTPS 출처 2개 이상 및 확인일의 기계 검사를 통과했다. 40개 장소의 `query`와 `day`는 API 계획과 모두 일치했다. 본문은 소개·장소 설명·섹션 문단 합산 1,582~1,679자, 가장 짧은 장소 설명은 185자다. 글마다 공식 출처는 4~5개다. 기존 당일치기 원고와 slug 중복은 없다. 시간표의 일차는 `day` 값으로 전달하며 `timeLabel`에는 중복 일차 표기를 제거했다.

API ID·좌표·사진과 사용허락·실물 검토는 별도 담당자가 처리하며 원고 작성자가 사진 검토 완료 값을 만들지 않았다. 최종 조립 후 발행 검증·반응형 UI·운영 배포 확인은 상위 작업의 별도 검사 대상이다.
