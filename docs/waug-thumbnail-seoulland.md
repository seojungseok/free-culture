# 서울랜드 대표 썸네일

2026-09-10 수정. 내장 image_gen 편집 기능 사용. 최종 파일은 public/ticket-images/seoulland-02624c146e22.jpg 한 장이며, 대표·목록·OG에서 같은 주소를 사용한다.

선택 문구: **서울랜드 / 아이와 가기 전 / 알아둘 것**. 어린이 요금 구분, 놀이기구 탑승 제한, 주차와 모바일 입장 준비를 다룬 본문에 맞춘다. ‘아이와 하루 나들이’는 실제 하루 코스까지 소개하는 인상을 줄 수 있고, ‘놀거리부터 이용 팁까지’는 개별 놀이기구 설명이 충분하지 않아 선택하지 않았다. 이용권 종류는 썸네일에서 빼고 본문에서 설명한다.

공공누리의 경기도 소유 과천_서울랜드2 사진(2012년), 제1유형 이용조건을 확인했다. 출처: https://www.kogl.or.kr/recommend/recommendDivView.do?division=img&recommendIdx=36992 . 사진의 촬영연도와 출처를 이미지 안과 본문 캡션에 표시한다.

최종 제작 지시: 실제 서울랜드 바이킹 사진을 전체 배경으로 사용하고 시설·풍경·구조를 새로 만들지 않는다. 사진을 작은 삽화처럼 배치하지 않는다. 장소명 ‘서울랜드’를 먼저 읽히게 하고, ‘아이와 가기 전’, ‘알아둘 것’을 간결하게 얹는다. 글자 아래에만 절제된 어두운 그라데이션을 사용한다. 넓은 단색 패널, 브랜드 대제목, 구매 문구, 물음표, 이용권 나열, 불필요한 아이콘을 넣지 않는다. 사진과 핵심 문구는 중앙에 가깝게 배치한다. ‘사진: 경기도 · 공공누리 1유형 (2012)’ 출처를 구분해 표시한다. 정확한 한글과 모바일 가독성을 확인한다.

추가 편집 지시: 기존 사진과 핵심 문구를 유지하고 출처만 제목 아래에서 제거해 오른쪽 하단으로 이동한다. 1200×630 기준 오른쪽 약 32px, 아래 약 28px 여백을 두며 작은 흰 글씨와 절제된 반투명 배경으로 구분한다. 원본 공공사진을 사용했으므로 출처와 촬영연도는 유지한다. 모든 썸네일에 실제 사용 출처만 표시하며, 공공사진이 없는 순수 생성 이미지에는 공공사진 출처를 붙이지 않는다.

검증: 1200×630 JPEG, 231,834바이트(226.4KiB). 로컬 브라우저 320px 목록 카드, 390px 상세, 1440px PC 상세에서 전체 비율·한글·가로 넘침 없음·사진 표현을 확인했고, 출처 위치 변경 후 390px 상세 화면을 다시 확인했다. 대표·카드·OG는 같은 파일을 참조한다. 공개 업로드 및 실제 카카오톡 미리보기 검증은 별도 단계이며, 이 로컬 검수로 완료 처리하지 않는다.
