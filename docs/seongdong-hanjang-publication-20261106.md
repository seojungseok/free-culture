## 수집과 목록

`data/curated-events.json`을 API 수집 파일과 분리하고 ID 기준으로 병합한다. 수집기가 `data/events.json`을 갱신해도 수동 등록은 유지된다. 서울·전국의 관련 홈 카드, 주말·무료 행사에 편집 우선순위를 적용한다. 다른 지역 선택과 카드 수는 보존하며 인기 순위로 설명하지 않는다. 무료 목록은 ‘곧 열리는 행사’와 ‘오늘 진행 중인 행사’를 구분한다.

## 자동 공개 종료

`2026-11-08T18:00:00+09:00`부터 공개하지 않는다. 운영자의 시스템 시각을 바꾸지 않는다.

- 행사 조회·검색·주변 추천·파생 목록을 현재 시각으로 필터링한다. 메모리 캐시도 만료 여부를 다시 검사한다.
- 행사 의존 목록·사이트맵은 종료 전 정적 캐시가 남지 않도록 처리한다.
- 원본 상세·별칭·게시 이미지 URL은 미들웨어에서 `410 Gone`, `noindex`, `no-store`를 반환한다. 사전 생성 페이지에도 먼저 적용된다.
- 열린 페이지의 만료 카드도 제거하고 갱신한다. 정상 상세 본문이나 사용자 보관함 원본 저장 내용은 삭제하지 않는다.
- 공개 종료이며 원고·감사 기록의 물리 삭제를 의미하지 않는다. 검색엔진의 기존 색인 제거 시점은 검색엔진의 재방문에 따른다.

## 검증

포스터·공식 일정·주소·요금·신청 차이를 별도 검수했다. 1280px/320px 브라우저에서 포스터·사진 2장·본문·링크를 확인했으며 320px에서 가로 넘침이 없다. 경계 시각·따뜻한 메모리 캐시·별칭·이미지·다른 상세 보존 테스트를 실행한다. 빌드·실제 서버 전후 HTTP·공개 배포 증거는 로컬 `.cache`에 기록한다. 아직 오지 않은 실제 종료 시각의 서버 결과나 검색 노출 증가를 확인했다고 보고하지 않는다.
