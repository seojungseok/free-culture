# 주말에 뭐하지 성장 작업 점검 (2026-09-24)

## 범위와 기준

- 목표는 이번 주말 갈 곳을 빠르게 고르게 돕는 정보 서비스다. 일 방문자 10,000명은 내부 목표이며 달성·순위 상승을 보장하지 않는다.
- 기존 URL, 행사·준비 가이드·입장권 콘텐츠, 제휴 원본 데이터와 수집 코드는 보존했다. 새 검색어 조합 URL은 만들지 않았다.
- Git 기록의 기존 행사 자료에서 이미 종료됐고 현재 목록에서 빠진 상세 URL 3,205개를 `data/events-archive.json`에 복원했다. 이 기록은 상세 주소에서만 조회하며 현재 행사 목록·사이트맵에는 추가하지 않는다. 수집기가 이후 종료된 행사를 버릴 때도 보존하도록 변경했다. 누락된 미래 일정은 임의로 복원하지 않는다.
- 저장소의 `data/events.json`에는 행사 963건이 있으며 2026-09-26~27 기간과 겹치는 행사는 466건이다. 같은 기간 서울 202, 경기 68, 인천 8, 부산 16, 제주 6건이다. 이 수치는 파일 스냅샷이며 실시간 운영·매진 상태를 뜻하지 않는다.
- `data/weekend-prep.json`에는 준비 글 44건, `data/waug/published.json`에는 입장권 안내 글 65건이 있다. 공개 여부는 발행 조건과 페이지 로직이 다시 결정한다.

방문자용 페이지의 클라이언트 import도 정리해 토스·숙소·쿠팡 제휴 주소가 해당 JS 청크에 실리지 않도록 했다. 제휴 관련 주소가 남은 청크는 `noindex`로 설정된 준비물 관리 화면용 1개다. 이 관리 URL은 접근 인증으로 보호되는 상태가 아니므로 실제 비공개 화면이라고 가정하지 않는다.

`daily.yml`, `coupang.yml`, `weekend-prep.yml`, `waug.yml`, `waug-editorial.yml`에는 수집·검토·발행 경로가 남아 있다. 데이터 유지 요청에 따라 자동화 자체는 바꾸지 않았다. 향후 제휴 재개는 중앙 설정과 광고 심사 상태를 함께 검토해야 한다.

## 검색과 탐색

- 기존 `/weekend`를 핵심 허브로 유지한다. 지역·방문일·목적 필터에 더해 실제 주말 행사 상세 링크와 서울·경기·인천·부산·제주 지역 허브의 서버 렌더 링크를 제공한다. 건수가 없는 지역은 이 구역에 억지로 채우지 않는다.
- 초기 필터 데이터는 지역별 행사 최대 12건과 테마별 선별 장소로 제한한다. 전체 행사 탐색은 기존 `/events`에서 계속 제공한다. 빌드된 `/weekend` HTML은 약 943KB에서 335KB로 줄었다. 필터 후보는 전체 데이터가 아니라 선별 목록임을 화면에 밝힌다.
- 기존 `/region/[code]`는 기간과 겹치는 행사, 무료·아이 동반·데이트·장소·코스·캠핑·맛집 데이터를 이미 분리한다. 데이터가 없는 분류는 표시하지 않으며 기존 URL을 유지한다.
- 행사 상세의 종료 안내에는 `/weekend`와 해당 지역 허브로 가는 다음 행동을 추가했다. 유효한 행사에는 기존 주변 추천과 같은 분야 행사 연결을 유지한다. 404 화면에도 주말·지역·아이 동반 탐색 링크를 둔다.
- 종료 행사 상세는 종료 안내와 당시 요금 표시를 사용하며 현재 예매용 구조화 데이터 `offers`를 출력하지 않는다. `/weekend` 필터 결과에서 지역 전체 행사와 지역 허브로 이동할 수 있다. 행사 자료 갱신일도 실제 저장 데이터의 시각으로 보여준다.
- 제목·설명·canonical·robots·기본 사이트맵은 이미 적용되어 있어 대량 변경하지 않았다. 검색 콘솔의 실제 쿼리·노출·클릭·평균 순위에 접근하지 못했으므로 신규 지역 조합 URL, 리디렉션, 대량 noindex는 근거 없이 시행하지 않았다.

## 날짜·성능·측정

- 한국시간 날짜 계산은 `lib/dates.ts`를 그대로 사용한다. 금·토·일·월 주말 경계, 일요일 주간 경계, 연말, UTC 15:00의 한국 날짜 전환을 `scripts/test-date-boundaries.cjs`로 확인한다.
- 방문자 렌더에서 제휴 API를 호출하지 않는다. 이번 변경으로 공공 API 호출이나 제3자 상품 스크립트를 추가하지 않았다. 제휴 상품 HTML 영역이 빠지므로 해당 영역의 이미지·링크도 전송하지 않는다.
- 기존 GA4 설정은 유지했다. 현재 검색 콘솔·GA4 실측에 접근하지 못했으므로 방문자 수, 페이지뷰 증가, 수익 증가는 보고하지 않는다. 이후 `/weekend` 유입, 지역 허브 이동, 상세→다음 페이지 이동, 모바일 이탈을 실제 분석 도구에서 비교해야 한다.
